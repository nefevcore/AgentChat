# 1. 里程碑总览（依赖序）

```
M0 地基 ──> M1 协议三纯库 ──> M2 数据根与授权 ──> M3 壳 boot ──┐
                │                                            ├─> M5 药丸形端到端 ──> M6 RSI 影子 ──> M7 ui 树 ──> M8 cutover
                └─> M4 宿主邮局化 ──────────────────────────┘
```

- 每个里程碑收口有一条**级联验收**（非仅单测）；
- M1 与 M2 无相互依赖可并行；M3/M4 各自依赖 M1+M2；M5 起串行；
- 跨会话推进：状态板（§5）是唯一进度事实源——新会话开工先读，收工回写。

## M8 cutover（恒等门导入脚本 + 产品面恒等收敛 + 切换；**切换前才做，不提前**——R-10；任务表 cr-517 细化）

> 三段式：**A 产品面恒等收敛**（M3-M7 的 mock/架构轴替身换主线等量真身）∥ **B 恒等门导入脚本**（R-10 代码化）→ **C 切换**（严格最后）。A 内部按「越接近用户可见表面越晚」排序：先收行集（8.1），再收编排（8.2/8.3），最后收 UI 表面（8.4）。
>
> B 段导入脚本语义（R-10 已裁，细节以 `src/docs/per-agent-instance-architecture.md` §R-10 为准）：
> - pairKey `a~b`（排序）→ 新会话 uuid 保留原键（**不改写**）+ 尾段 ~agent 提取 agent id；旧格式知识（pairKey 构造/段行形态/marker 形态）全部圈禁在导入脚本内，新系统运行时零旧格式知识（R-10「旧格式知识圈禁」）；
> - 会话内文件分三类：**恒等拷贝**（summary.md + 其余未知文件原样）/**改写**（messages.jsonl 行协议重写 + journal/ 目录重建 partials.jsonl + subcalls.jsonl seq 重排——一文件一 writer 重分配，单调，写入前校验）/**丢弃**（.migrated marker——旧系统专属状态，新账本无此概念）；
> - 旧 steps[]/reasoning_content → journal-step 行重建（工具卡全字段保留）；partial:true 行不入新账本（死数据，旧根保真），未收束 run 的部分行物化为「中断收束段行」同形迁移（旧 recoverJournal 投影语义）；
> - header 增 participants（= pairKey 两端）+ kind（1v1='agent-pair'、single='user'、群=gid）；旧无 envelope 字段补 null（additive 可空）；
> - 恒等门：预演目录（preview/sandbox/）+ 全量校验（消息条数/顺序/role+agent_id+content 全字段/工具卡完整）+ fail-loud 原子换名（目录 rename，失败即中止不落半态）；
> - **主线原样保留 = 终极回滚**：旧 sessions/ 不动不删（用户数据不做不可逆操作）。
