CONTRACTS · cr-121

1c · 焦点 · 命中区 · 开关语义 · 忙指示 · 令牌

四类契约在 kit 内此前整体缺失——它们无法靠肉眼评审，只能靠实物 + 测试锁

可聚焦徽章

按 Tab 走一遍本格：焦点环全部来自 L0 单源 --focus-ring（tokens.css 全局 :focus-visible），组件不得自建——此前 kit 内 0 条 focus 规则，26 条散落业务面。

焦点环（键盘 Tab 可见）

开关 可视 34×18 · 命中 24 抓手 可视 36×4 · 命中 24

小控件一律以透明覆盖层 / 伪元素把命中区撑到 --hit-min(24px)（WCAG 2.2 · 2.5.8）：视觉尺寸不放大，可点范围放大。开关的 input 也从 display:none 改成透明覆盖——否则读屏读不到 role/name/checked。

命中区与可达性（开关 / Sheet 抓手）

关（中性灰） 开（主色） gated（琥珀 = 门禁未过） disabled

语义纠正：关 ≠ 红。旧「红绿开关」把危险色（err）与关闭态混成一色，与错误徽章互相稀释；现在状态色只陈述结果 / 状态，控件开合用中性 + 主色，红留给阻断与错误。

开关四态（语义色归位）

busy · 行内 13 busy · 独立 18

归一 4 处 spin-ring + main.css 全局 + toast / FeedbackNotice 的 loader 旋转：形状轴归 BusyRing；色轴恒主色靛蓝（cr-122 合并原 busy 琥珀 / running 靛蓝两档——消费侧无规律支撑二分，且与 StarAvatar 运行光环同语言）。默认 aria-hidden（装饰），独立等待位传 label 才播报。

BusyRing（新原语 · 忙指示唯一源）

40%normal 76%high 90%critical

RingProgress 三档语义色全部令牌化（此前 4 个硬编码 hex）：normal / high / critical → ok / warn / err -graphic 图形档，随主题自动换档（cr-122 收敛——moderate 与 high 用户动作指引相同；cr-123 环描边走图形档 3.0 线）。

用量三档（硬编码 hex 清零）

--motion-scale 动效时长归一；reduced-motion 归零（kit 内 14 处动画此前无一响应）
--hit-min 24px 可点下限（开关 / 关闭键 / 抓手 / 导航点阵）
--focus-ring 键盘焦点唯一源（此前 kit 内 0 条 focus 规则）
--on-primary 主色实底前景（白字 on #818cf8 仅 2.99 → 暗色改深字 5.83）
--elev-hairline 暗色浮层顶缘高光（暗影投在 #1a1a1a 上不可见）
--*-graphic 语义图形档（cr-123）：环描边/状态点/色条走 3.0 线，文字仍用墨色档 4.5 线
--fs-* / --ctl-h-* 字号五档 + 控件高 28/32/40（此前全仓 31 种字号并存）

全部有测试锁：src/webui/tests/contrast-tokens.test.ts 解析 tokens / badge / row / StarAvatar / starColor 本体后断言比值——改色漏改即红灯，不再靠「看起来还行」。
