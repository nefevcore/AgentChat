两种事件模式（公开约定，新增事件必须二选一写进目录）

waterfall（拦截/改写/否决）可变载体（XxxCall 对象）沿链传递；监听器变异载体后 next() 委托，不调 = 短路。next() 不携带参数——改写输入唯一方式 = 变异载体；实现侧必须在 waterfall 返回之后才读载体字段
emit（纯通知）多方订阅、发送方不关心谁在听（历史/审计/WS 广播）。末参永不为函数（agentGate 判定前提，静态测试锁定）
@scope run | hostrun 域 = 分发发生在唯一 Agent 的执行里（loop/tool/router/llm/conversation-steered）→ 才有 agentOf 读取器、才可门控；host 域 = 宿主上下文（config/plugin/webui/ws/job/agents-updated…）。载荷带 agentId ≠ run 域

两级门控（两层不混）

Agent 级 · agentGate（ac-gate-core）waterfall 停用 = 机械 return next()（末参函数判定）；emit 停用 = 跳过；facet 子键覆盖回落行为级。软依赖 agents.settingsOf：deepMerge(config.settings[名], agent.settings[名])（全局默认层 ∪ 差异层；enabled 可覆盖回 true）
进程级 · ac-event-policy(插件 × 事件) 停用集 events.disabled；internal/listener bail 吞注册（吞注册 ≠ veto，剩余监听器照常构链）+ boot 末一次性清扫 + 行 reload 自追清扫；internal/* 恒放行防自锁
目录 · A1 注册制行包入口自述 export const extension: ExtensionMeta（契约住 ac-extension-core）；ac-web-api 扫 cordis registry 聚合——行装载即条目在、卸载即失；监听器级 {event, 角色, facet}；events/descriptions RPC 交叉执行链
