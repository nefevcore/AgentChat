## 5. 踩坑存档（下轮勿重蹈）

1. **宿主重启杀会话**：agent 跑在宿主进程里，让用户重启宿主=杀自己——改代码后让用户重启时，
   先把状态落盘（文档/CR），新会话从本文恢复。
2. **宿主重启也杀我起的后台 relay**：每次宿主重启后要先重起 relay 再触发 connect（时序：relay
   就位赶在宿主 kkRetries 耗尽前，否则等 60s 退避）。
3. **PS 中文重定向编码**：PS > 重定向 UTF-16 炸 Android XML；中文字符串进 .ps1（UTF-8 无 BOM
   写入）PS5 按 ANSI 解析炸语法——ps1 只写 ASCII，中文走参数或代码内拼接。
4. **uiautomator dump 抓不到 WebView 内容**——查页面用 CDP（§4）。dump 里的 MIUI
   theme_compatibility FileNotFoundException 是 MIUI 噪音，忽略。
5. **adb shell input text** 不支持 & % 等特殊字符的可靠输入——URI 灌入用 am start -d
   （deep link）或 prefs 直写，不走 input text。
6. **两个浏览器实例互不知晓**：agent 的 browser 工具与用户自己的页面是两个窗口、两个组件
   状态——agent 发起的配对会话用户看不到（⑦的互抢场景）。会话类操作让用户页面发起，agent 只读状态。
