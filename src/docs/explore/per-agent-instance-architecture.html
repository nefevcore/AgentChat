图 4 · 自进化五步闭环 + 相互恢复环

处置语义 = rollback 非 retry → 环收敛；最小工程量 = 红色三件。

自进化闭环
宿主重启 = 会话里的一次可观察事件
0 版本指纹缺 —— 变化的锚点
1 快照部分 · last-known-good
2+3 换装已有 · cordis 事务原子
4 观察回执缺 · 成功指纹+失败回退
5 验收 / 回滚判定缺 · agent 自判 + bench 门
通过 → 拍新快照
相互恢复环（rollback）每次回退指向 last-known-good → 有限步收敛；两侧死亡互不传染；同时死 → supervisor 保底
守护原子（变更面外）① 快照链（boot 成功+冒烟过才拍 · 三层覆盖）② 回退通道 —— 进化器不能进化逃生门
最小工程量 = 红色三件版本指纹 · 观察回执 · 验收判定——其余机构（换装/patch/熔断/backupDir）全部已有
