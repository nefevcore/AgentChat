# cr-1209 agents/delete 会话面级联（D1：硬删全部）

## 动机
cr-1208 诊断出三条断裂链，其二是 agents/delete 只删树：
`agents/delete` = `fs.rmSync(agents/<id>/)`（agents-row.ts removeAgent）——树外的会话面全部成为孤儿：
1. meta/sessions/<sid>.json 中该 agent 的会话元数据（agent 域消失后列表并集不再捞它，不可见孤儿堆积）；
2. 对端 agent 域的会话副本（agents/<other>/sessions/<sid>——单方会话多域各一份，删本侧不清对端）；
3. 群名册仍含已删成员 + 成员流 gid~<id> 残留；
4. 会话快照目录。

## 裁决（用户 2026-11-22）
D1 硬删全部：清 meta/sessions 该 agent 会话 + 对端副本 + 群名册移除并清成员流 + 快照（与「删除即清理」cr-1184 同向）。

## 改动面

### 新增纯库 packages/ac-host-rows/src/agent-cascade.ts
两段式（顺序是语义要求——会话键住在将被删除的树里）：
- `collectAgentTraces(dataRoot, agentId)`：删树前枚举；① agents/<id>/sessions/ 目录名 ② meta/sessions 中 agentId 归属本 agent 的独立会话 ③ 名册含该 agent 的群。
- `cleanupAgentTraces(dataRoot, agentId, traces)`：删树后清；会话面（各 agent 域残留目录含 journal-only / meta 文件 / 快照 / 未读计数）+ 群面（名册移出写回 / 被删者成员流 gid~<id> 在各域副本 / 快照）。
- 边界：其他成员的私有流 gid~<m> 保留（群还在，历史不动）；群解散才全清（group/delete）。幂等（目录缺席即跳过）。

### RPC 编排 packages/ac-host-rows/src/agent-admin-row.ts
- `options.dataRoot` 新增（缺席 = 只删树，旧行为良定义降级）。
- `agents/delete`：collect → removeAgent → 成功才 cleanup → 逐群广播 group/member-removed。
- 删树失败（无此身份）不级联——宁可留孤儿，不制造「agent 还在、数据没了」。

### 单源下沉（零冗余）
- ac-core-utils/groups.ts：新增 `writeGroupConfig`（groups-row 本地 writeConfig 私有实现删除，5 处调用点改用它）。
- ac-ledger/user.ts：新增 `metaSessionsDir`（singles-row 本地私有实现删除）。
- ac-file-snapshots/store.ts：`dropConversation` 诚实计数（目录不存在 = 0，此前 rmSync force 恒返回 1 虚报）。

### 接线 apps/host/boot.ts
