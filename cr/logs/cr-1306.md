# cr-1306 aggOrder 存量归一化（段行 → v2 事件行）

> 2026-11-24 · #ledger · 前置：cr-1305（判据达成：新代已不产段行，存量 16341 条挡住读侧退役）。
> 用户裁决 2026-11-24：做一次性数据根归一化批。

## 目标与判据

把盘上 `source:'segment'` 段行（v1 settlement 聚合轨迹）展开成 v2 相位事件行，
使读侧 `aggOrder` 顺序簿分支可退役。

**等价判据**：同一 run 的 `foldStepsOf` 产出语义恒等——content / reasoning /
textBeforeTools / toolCalls（id/name/arguments/result/subcall/durationMs） /
aborted / reasoningMs / textMs / elapsedMs / usage / stepId / ts 全等。

**两处显式豁免**（均在 cr 记录中声明，非静默）：
1. **seq**：整文件原子重写 = writer 重分配（`writer` 语义），原 seq 的直播配对
   语义（cr-772 B2）只对在途 run 有效；老会话无该需求。
2. **无结果调用的 synth**：聚合路径原样保留 `result:null`，事件重建路径按 fold
   既有规则合成（finish 正常 → `{ok:true}`；finish 异常 → aborted ?
   `TOOL_NOT_STARTED` : `TOOL_OUTCOME_UNKNOWN`）。差异方向是「向 v2 写面收敛」，
   非数据丢失。对拍时对 before 侧套同一 synth 规则（不是掩盖差异，是对齐语义）。

## 等价映射设计（三个关键点）

1. **相位序由行序表达**：v2 事件路径按 `firstContentAt < firstCallAt` 推导
   `textBeforeTools`（fold-core L110-111，该字段在写面已退役）→ 正文行须先于
   工具行入文件序；seq 由工具按最终文件序统一分配。
2. **meter 只能经 reasoning/content 承载**（`placeEvent` 只从这两词收 meters，
   L342）→ 纯工具步无此类行时，合成空 text 的 reasoning 行承载，否则计量丢失
   （工具报告 `synthesizedMeterRows` 可见）。
3. **subcall 只产 result 行**：`foldStepsOf` 按 toolCallId 首段分组进宿主卡
   （L50/74-82），不与 tool-call 配对。

实现：`packages/ac-ledger-core/src/segment-normalize.ts`（纯函数，零 fs 零 cordis）。

## 遗留：读侧退役的前置

盘上现已无段行 → `aggOrder` 分支对**现行数据**是死代码。但**不能立即删**：

- `session-chain.ts` 的 `segmentRow`（迁移边）在处理 v1 输入时**仍会产段行**
  （幂等重入 / 未来导入路径）；
- `source='inject'` 行的 v1 读分支与段行共用 aggOrder（现行 0 条，但迁移边仍产
  `inject` 型 v2 行——需一并核对）。

→ 读侧退役须与「迁移边改为直产 v2 行」同批（并调整 `sessionFactsEqual` 的
aggregated 对拍面）。已作为下一步候选记录，不在本批。
