## 裁决

1. 物化而非触发压缩：压缩轮要跑 LLM 生成新摘要（花钱 + 需 idle 窗口）；物化是纯数据
   搬家（存量文本 → V3 行），语义等价（同文本同单源位）。
2. 摘要单源序收敛为一级（foldDigestOf）：V3 行正文以 context 行进 picked/时间线（估算
   器已计量——200 字 = 60 token 实测），system 头不再另发防双计。
3. 边界保留：compaction 事件 summary 字段仍在盘上（audit 面），仅读面退役；未来压缩轮
   若无新摘要（无提交退化），回放头为空——「回落上一代概要」语义随之退役（cr-1160 P3
   的 summaryOmitted 机制保留在 compactions 事实面，不再影响回放头）。
