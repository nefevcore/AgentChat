# cr-1132 注入卡挂靠结构修复：ViewRow 时间全序 + 投影层锚定

- **日期**：2026-11-16
- **标签**：#webui #session
- **状态**：done
- **计划**：docs/design/webui/inject-card-anchoring-plan.md（cr-1131 立项）

## 根因（计划 §一实证，本 CR 落实施）

两层结构缺陷叠加：
1. foldViewRecords 输出无全序（尾段三族追加在数组尾），web-api 分页 slice 在无序数组上切窗 → 全部历史注入卡恒挤进首屏；
2. 注入卡归属由前端在分页窗口局部猜（buildTurns ownable/pending/尾挂三段启发），v1 存量 viewer 域直落行的 agent_id='user' 是落账恒值却被当真实归属 → 猜错降级为独立 system 空轮。

## 改动面（批 1-5）

### 批 1：foldViewRecords 时间全序（fold.ts）
- 尾段三族（error 红条 / 直落 context / 机制 event）并入主时间线稳定排序（ts 主序 + 输入序 tiebreak；无 ts 行守尾）——foldLlmReplay 同款语义；
- 活投影子行带步 ts、盲区行带 run 末事实 ts（foldLlmReplay 孤儿 slot 同源派生）；
- 位次升契约：分页窗口 = 时间窗，web-api slice 零改动自动变对。

### 批 2：anchor 派生 + viewer 域归属归一（fold.ts/view.ts/events-v2.ts/user.ts）
- ContextEvent 增 domain（归一化层填）；viewer 域（agents/user）直落行 agent_id 归一为无归属（落盘不动）；
- 无 run 锚直落卡派生 anchor = 时间线上最近后续 agent 发言行 message_id（无后续前向回落；全会话无 agent 行 → 无锚）；
- UserReplayRow.messageId 透出 → 主投影发言行升格携带 message_id（anchor 目标）。

### 批 3：前端坍缩（feed.ts/historyApi.ts/types.ts/feed-core.ts）
- anchor 随行透传（ViewRow → PSessionRecord → toHistoryMessages → ChatMessage → InjectCard）；
- buildTurns 挂靠坍缩：按 anchor 挂（目标在窗口内精确挂目标轮头/前向回落挂轮尾）→ 锚被窗口边界切掉剥锚走位置启发 → 全会话无 agent 轮才降级 system 空轮。

### 批 4：face-shell 子会话视图收编单源（face-shell.ts）
- subagents/history 投影段（~100 行判据复制）删除，切 foldSession + foldViewRecords（subcallsOf 钩子直读子会话目录）；
- 判据复制清零（grep 断言）；子会话无 user 域——父行同为 assistant + agent_id（下游管线等价）。

### 批 5：文档 + 测试
- fold.test.ts 补 4 个契约测试（时间全序 / anchor 派生 / viewer 归一 / 无锚降级）；inject-card.test.ts 补 4 个锚挂靠测试；
- render-contract.md 状态行 + §五-3 互引；计划文档标已实施。
