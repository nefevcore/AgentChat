# cr-1191 压缩后续用双缺陷修复（cr-1190 V3 实施的实证续修）

## 现场与根因（本会话活体实证）

V3 压缩（cr-1190）后继续会话暴露两缺陷，均在当前会话（01a1fd60…，boundarySeq=1084，摘要行 seq=1085）实测复现：

### 1. 技能加载失效（load_skill 回执 injected 但正文永不进上下文）

- seq=176 技能注入行（agentchat-dev+cr，10.7KB）被 boundary 1084 shadow——回放不可见但物理在场。
- ac-skill 跨 run 去重走 `recordsFor()`（「已落账在场判定」），该读面**不过滤压缩边界**——旧行在场 → 误判「已注入」→ after-execute 登记 return → before-step 无 pending → 注入链整体静默断链。
- 修：recordsFor 加压缩边界过滤（rowShadowedBy 单源谓词——时刻放行 → seq 位置维 → 时刻维，与回放口径一致）。v1 无 seq 行保守放行（原口径不变）。

### 2. 前端占用读数新旧两值来回跳变

三路跳变源：
- **回落路径不滤 shadowed**：session/tokens 行缺席时回落 replayTokensOf 全量盘读（含旧代 ≈650K），索引路径 activeContextTokens 只计活跃代（149K）——两路径口径分叉。
- **锚点跨代毒对**：cr-1135 锚点校准假设「P/E 同拍同代」；压缩后 P（lastRunPrompt=451K 旧代）与 E（盘读 149K 新代）断层，r=3.02 落在钳制带 [0.5,4] 内被采信 → displayTotal=450K；归档帧清锚（149K）后下一拍又毒采（450K）——来回拉锯。
- **KV 尾点残留**：livePrompt 倒序捞「最近有 prompt 的点」；归档后新 run 未起时捞到旧代 451K 尾点。

修法：
- face-ops replayTokensOf 回落路径加 shadowed 过滤（与 archive.ts estimateOf activeOnly 同型）+ V3 摘要单源（digest 行在场时其正文已在计量集，不再加 summary 头——防双计）。
- archive.ts estimateOf 同步 V3 摘要单源（阈值口径同 bug：digest 行 content 与 {summary} 头双计）。
- TokenGauge sampleAnchorRatio 跨代守卫：P/E 超出 [0.33, 3]（正常估算器系统偏差 <3x，跨代断层 ≥3.03x 实测）弃样保持 null（回落净估算），不再钳制采信。
- TokenGauge 归档 watch 补清 kvPoints（livePrompt 不捞旧代尾点）。

## 活体验证（新壳/新宿主进程，重启后）

- **技能注入闭环**：壳重启后调 load_skill(plugin-dev + cr)——两个技能正文以 `<system-reminder>` 形态真实进入 run 上下文（此前只回执 injected、正文永不进场）。修复前该会话 seq=176 技能行被 boundary 1084 shadow 却被去重看见；修复后 recordsFor 过滤生效，去重正确判「未注入」→ 登记 → before-step 注入。
- **两路径读数对齐**（同一真实会话 01a1fd60）：回落路径 replayTokensOf = 288,613 vs 索引 activeContextTokens = 290,416（差 0.6%）；修复前 650K vs 149K（4.4 倍断层）——跳变主源消除。
- 技能注入行的落账时机 = run 收束（cr-971 消费点机制 + 收束兜底 flushPendingInjects，service.ts L766）——既有设计，非缺陷；跨 run 去重在下个 run 生效。

## 落账闭环实证（run 收束后）

同一账本两条技能注入行的最终形态：

| seq | 技能 | shadowed（by boundary 1084） | 语义 |
|---|---|---|---|
| 176 | agentchat-dev + cr | **true** | 压缩前代——回放不可见，recordsFor 不投影 → 去重不判「已注入」 |
| 1607 | cr + plugin-dev | **false** | 压缩后代——回放可见，recordsFor 投影 → 去重判「已注入」（下个 run 不重复注入） |

即修复后的完整链路：旧代被 shadow 的技能行不再阻断去重（缺陷根除）→ load_skill 真实注入正文 → 落账新行于活跃代 → 后续 run 正确去重。

占用读数（修复后单值稳定）：contextTokens = 297,393（29.74%），与索引路径 290,416 + 本轮增量同量级——修复前 149K↔650K 双值拉锯态消除。
