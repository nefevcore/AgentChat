# cr-1288 conversation 通道浏览器侧 process 未定义修复

- 2026-11-24

## 动机

Web GUI（http://localhost:3830/）行装载失败：
`ac-client-ui-conversation` 抛 `ReferenceError: process is not defined`（dist/index.js:1247），
下游 `Cannot read properties of undefined (reading 'init')` 连锁。

## 根因

cr-1281 影子对拍开关在 `client/feed-core.ts` 直读 `process.env.AC_SHADOW_MERGE_ALIGN`。
该源码进浏览器通道 bundle（client/dist），浏览器无 `process` 全局——测试（Node/vitest）在场
所以全绿，浏览器装载即炸。非「没编译」：dist 是新构建，问题在源码本身。

## 改动

- `packages/ac-client-ui-conversation/client/feed-core.ts`：读数改环境守卫
  `typeof process !== 'undefined' && process.env.… === '1'`——Node 测试进程语义不变，
  浏览器缺省 false。
- 重跑 `node apps/ui/scripts/build-channel.mjs conversation` 重建通道产物；
  全仓扫描确认其余 client 源无裸 `process.env` 直读。

## 验证

- `pnpm --filter ac-client-ui-conversation test`：73 文件 / 389 例全过（含 cr-1281 影子用例）。
- 浏览器实测 3830：conversation 行装载成功，会话视图/转录/输入框/挂件全渲染。
