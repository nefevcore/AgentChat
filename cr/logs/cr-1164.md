## 动机

timer-v3 设计（cr-1161）裁决：timer 终态是「没有代码执行面」。本 CR 落实「下一步」批——ac-timer-core 契约/推导 + timers 行哑匹配 + face/UI 换轨 + v2→v3 迁移，三病灶（执行面税 / 授权旁路 / 不可静态解释）全断。

## 改动面

- **ac-timer-core**（换轨重写）：
  - 契约 `TimerEntry`（when OR 触发词汇：once/daily/weekly/every{base 三形态,jitter}/source{on,match,cooldown} + gates AND + until + missed + action）+ `validateTimerEntries` 静态校验单源。
  - 推导纯函数：`nextGridMs`/`lastDueMs`（owner 时区墙钟网格，恒 24h；after-last 链式；jitter 每刻重抖不累积；armedAt 为 catchup 下界——新条目不回补历史刻）、`gatesPass`（hours 含跨午夜形）、`previewFires`（静态预览，after-last 标 chained）、`matchRow`（v1 六算子，字段缺席不命中）。
  - 迁移编译器 `migrateLegacyEntry`（§八映射表数据→数据直译）；`isScriptEntryShape`（v2 脚本判据——boot 丢弃归档）。
  - v2 脚本面全退役（TimerCheckFn 族 / compileEntry / inspectVerdict / makeTimerUtils 等）。
- **timers-row**（换轨重写引擎）：
  - 哑排程：arm → setTimeout 自续链 → fire → 记账/审计 → re-arm；catchup-once（lastDue > max(lastFired, armed) 且门命中）与未来刻取最小；过期 once 出局归档；纯源条目 dormant（source-unavailable——source 行为再下一批）。
  - 记账数值化：armedAt/lastFiredAt/nextAtCache 一律纪元毫秒——**localISO 秒级截断曾致 catchup 判据亚秒永真（once 7ms 循环重投，实测修复）**；显示层再转 localISO。
  - 审计 `meta/timer/audit.jsonl`（滚动 1MB→.old）；投递失败退避 1m→5m→30m、连续 5 次停排；远期目标 2^30ms 中继重算。
  - boot 迁移：timer.json 升 {version:3}（.bak 备份）；v1 5 模式直译、v2 脚本丢弃归档（reason script-face-retired）、简化全局形状归一；state.json 记账 key 迁移（executedCount→firedCount 等）。
  - gate/exec 预检退役；worker（timer-check-worker.ts）删除。
- **timer-face**（换轨）：set = 纯数据写（校验单源，无 dry-run）+ 静态预览返回；test = 预览 + match 模拟求值；list v5（dormantReason/chained/schedule 摘要）；GUIDELINES_TIMER 文案换轨（保留「主动用 timer(action="set")」锚——cr-1114 测试契约）。
- **UI**：TimerPane 脚本编辑器 → 触发词汇分栏表单（kind 分栏 + 门 + 终结 + 停机策略；源触发保留不覆盖）；GlobalTimerHost 兼容 {version:3,entries} 形状；类型面 TimerScriptEntry→TimerEntry 全仓换名（timerApi/TimersPanel/useAgentSettings/AgentPane/face-ops）。

## 裁决与踩坑

- 记账时刻字段必须毫秒精度数值——ISO 秒级截断 + catchup 判据（lastFired > due）在亚秒刻永真，once 条目 7ms 循环重投。
- 迁移存量核实：home/ 数据根 timer.json 存量为零——v2 脚本条目丢弃归档零损失（设计 §八预判成立）。
- 审计行落位（§十一开放项）：meta/timer/audit.jsonl 滚动文件（设计文档已回勾）。
