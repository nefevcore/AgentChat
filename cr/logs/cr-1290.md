# cr-1290 collab-tools GROUP_CONTRACT 段 settingsOf 判空

> 2026-11-24 · #render-pipeline · 现场来源：17:29 tester 壳「信封处理失败
> TypeError: Cannot read properties of undefined (reading 'contractText')」

## 根因

ac-collab-tools GROUP_CONTRACT prompt section（cr-944 P3 静态化引入）：

```ts
const s = ctx.agents.settingsOf(agent, 'group') as { contractText?: unknown };
const override = typeof s.contractText === ...
```

settingsOf 合成缺席时返回 undefined（壳垫片 globalSettings 恒 undefined
——壳无全局层；agent 无 'settings.group' 键时 a/g 双缺席 → undefined）。
tester Agent 无 agents/<id>/config.json（虚拟注册态）→ 必然 undefined →
读 .contractText 抛 TypeError → 信封（群消息唤起 run）处理失败。

宿主侧先例（timers-row layerOf）早有判空防御（`as T | undefined` + 回落
`{}`）——collab-tools 此处漏了对齐。

## 修复

`as { contractText?: unknown } | undefined` + `s?.contractText`——
缺席回落正典 GROUP_CONTRACT_TEXT（语义不变：缺省 = 正典）。

## 验证

typecheck ✓ / check:deps ✓ / 定向 lint ✓（包无测试目录——防御形态与
timers-row 同款，行为面由群聊集成链覆盖）。

## 运行时生效

壳侧装载行（ac-collab-tools = 壳基座装配）→ restart_shell 后生效。
