# cr-1333 IM 白名单扩围：用户参与注入行（steer 插话/ask 作答）打标

- 裁决（用户 2026-11-26）：中途 steer 的消息、ask_questions 作答也算用户参与的消息，应并入 IM 档。
- 前序：cr-1332（IM 白名单——delivered 行集）；本批为扩围。

## 数据面（实施前核实）

| 链 | 落账形态 | injectSource |
|---|---|---|
| busy-steer（壳 driveRun steer 分支） | inject 事件行（loop/inject-consumed → journalInject） | 'steer'（缺省词） |
| ask 作答（busy steer 路径） | 同上 | 'durable-interaction'（injectMeta 优先；payload.outcome='answered'） |
| ask 作答（idle 注入路径） | call.inject → inject-consumed → journalInject | 'durable-interaction'（同上） |
| ask 作答（steer 落空 → late-reply deliver） | 入站行（receiveEnvelope 全链） | 已打 delivered:true（cr-1332 覆盖） |
| ask 超时未响应 | 同 ask 注入 | 'durable-interaction' + outcome='timeout'——系统通知非用户消息 |

开放规约：`USER_PARTICIPATION_INJECT` 词表——新的用户参与型注入面在 ac-ledger service.ts 登记；材料类注入（skill/memory/datetime）缺省不打标。
