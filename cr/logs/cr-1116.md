# cr-1116 plugin-registry 插件目录页修复（数据面重接 + 文案对齐）

## 根因
- 后端 cr-485 起 plugin/patch-list|set|reset 三 RPC 整体替换为 throw（行集偏好改 rows/list|set|reset 恒冷生效），前端 PluginLibraryPane/pluginApi 未跟随——停用开关/批量还原整个急救面点了就报错（fail-soft 吞掉后呈现全启用假象）。
- 文案仍描述 cordis.yml × cordis.patch.yml 旧模型（现行 = 菜单合成 cr-1022 + host-rows.json 偏好）。
- 「还原到最小可运行集」按钮调 patch-reset mode=minimal——后端只有 rows/reset（全量复位），无 minimal 实现 = 死按钮。

## 改动面
- pluginApi.ts：getPatchList→getRowPrefs（rows/list）；setPluginPatch→setRowPref（rows/set，恒冷）；resetPluginPatches→resetRowPrefs（rows/reset）；删 minimal 路径。返回形状对齐 HostRowsView。
- PluginLibraryPane.vue：patches 锚点改 rows 视图（按行 id 查 disabled）；flash 文案恒冷生效；删 minimal 按钮；标题/徽章/确认弹窗文案改行偏好口径。
- ExtToolsPane.vue：装载即生效徽章 title 更新。
- tests/plugin-registry-data.test.ts：patch 用例改 rows 断言。
