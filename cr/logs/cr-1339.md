## 背景与裁决

- agent~agent 委托桶里 to=user **fail-loud 拒绝**（中途向用户冒话语义未定义，静默错桶不如显式报错）；

## 改动面

### 1. ac-collab-tools/src/index.ts（核心两刀）

**send_agent 虚拟端点分支语境路由**（to=user 按 call.conversationId 键形归一）：
- uuid 形（single 桶）→ 直投当前 single 桶（修错桶 bug：此前 pairKey 落 1v1 对桶，mid-run 通报静默丢失）；
- viewer 对桶 / 无会话键 / 自会话 / plain 兜底 → user 对桶（M19 语义不变）；
- 群语境（g- 形本体键全键查册 / gid~self 成员流键+群登记）→ fail-loud 引导 send_group；
- agent~agent 委托桶（两端无 user，非本壳自会话键）→ fail-loud 拒绝文案。

**send_group group_id 缺省化**：群语境缺省取当前群（本体键全键 / 成员流键 left 查册）；非群语境缺省报错引导 list_groups。required 收窄为 ['message']。

**DIRECT_IM_CONTRACT 段**：注入判据扩 uuid 形（single 会话也是「用户面前」形态）；段文「送达用户」→「送达当前会话」。

**send_agent description**：补语境路由语义（群内不可用 / 委托会话拒绝）。

## 语义边界备忘

- 群登记消歧：gid~self 与 a~self 键面不可辨（cr-1213 公理）——靠 group.get(gid) 在册判定，
  群行未装/群不存在时同形键落委托判定（此时 to=user 的委托拒绝语义正确）。
- 自会话键（a~a）豁免委托拒绝：自会话 run（定时推送等）中途通报用户 = 语境路由缺省面。
- 单测桩 ctx.get('group') 返回 undefined 时一切键形走既有语义——工具对群行未装载零依赖。
