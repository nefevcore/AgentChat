# cr-1203 workspace-files 全局设置层死键清理（agents.settings → settings）

## 动机

cr-1202 修复 timers-row 死键时发现的同款漂移：
`workspace-files.ts globalAgentSettings` 直读 config.json 的
`agents?.settings`——死键（config.json 无 agents 顶层键；主线合成口
ac-agents settingsOf 读顶层 'settings'）。影响：security.workdir 全局
层配置（为所有 Agent 设缺省工作区目录）自引入起恒不生效。

## 改动

1. `packages/ac-host-rows/src/workspace-files.ts` globalAgentSettings：
   `raw.agents?.settings` → `raw.settings`，附注释（cr 号 + 死键来历）。
   纯函数模块无 ctx——保持直读文件形态（改值经 config 行写，读每现查）。
2. `packages/ac-host-rows/tests/workspace-files.test.ts` 新增锁定用例：
   全局层 `settings.security.workdir` → agentWorkdirOf 生效；死键
   `agents.settings` 形态写盘不得生效（防回归）。

## 验证

  （含新用例）；
- typecheck 0 错 / lint exit 0（余 4 错均为他人在途文件
  step-race-wipe.test.ts）；
- 全量 unit 档：**454/454 文件通过**（exit 0，落盘 sandbox/test-unit-cr1203.log）。
