# cr-1186 · user 虚拟身份被保留字闸误伤除名（用户头像全域消失）

- **日期**：2026-11-21　**状态**：done　**标签**：#roster #regression　**承接**：→cr-1175

## 症状

前端用户头像全域消失（消息气泡 / 名册 / 设置页）。Agent 头像正常。

## 根因链

1. cr-1175 D6（75b018ce）为防「虚构端点劫持可达表」，把保留字拒斥（host/user/@ 前缀）
   **内嵌**进 `isAgentIdentity`（ac-agents-core/tree.ts）——而该函数是名册投影的词形闸。
2. `rosterConfigs`（ac-host-webui/web-api.ts:151）用 `isAgentIdentity` 过滤 agents/ 目录 →
   `user` 被除名 → `agents/list` 不含 user 条目（实测 12 个 agent、无 user）。
3. 前端 `getAgentAvatar('user')` 从名册查 → 恒 null → `UserMessage` 的 `v-if="senderAvatar"`
   不渲染 → 头像消失。数据面完好（agents/user/avatar.png 856KB 在、agent.json name=风栗、
   HTTP 路由 /api/agents/user/avatar 200 正常）。

## 裁决：词形单义 vs 创建闸分离

- `isAgentIdentity` 回归**纯词形单义**（只拒 `~`/空串）：user 是合法虚拟身份（viewer 实体，
  名册/头像/消息发送者面的投影源，档案与头像是数据根真实实体）。
- 保留字拒斥归**三处显式闸**（cr-1175 D6 原意）：sanitize（write.ts:62）、ensureAgent
  （apps/host/orchestrator.ts:219）、createFromTemplate（agents-row.ts:227）——全部直调
  `isReservedEndpointId`，不经过 isAgentIdentity。防的是「出生口虚构端点劫持」，不是名册投影。
- post-office router 的 infraSender 判定也直调 isReservedEndpointId，不受影响。

## 改动面

- `packages/ac-agents-core/src/tree.ts`：isAgentIdentity 去 `!isReservedEndpointId(id)` + 注释裁决。
- `packages/ac-agents-core/tests/agents-core.test.ts`：词形单义锁（user/host 放行、~ 拒斥）。
- `packages/ac-host-webui/tests/e2e-host-web.test.ts`：回归锁——agents/list 必投影 user 虚拟身份
  （name/hasAvatar/avatarVersion 三断言，正是本次事故消失的载荷）。
