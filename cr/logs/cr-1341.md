# cr-1341 collab-tools 列入预设模板基础行集

## 背景与裁决

用户要求 collab-tools 成为「基础行集」（所有 Agent 默认装备）。首选落点 shell.patch.yml 经实测否决：
cr-1022 装配模型下用户全局层只做停用与 config（定义入口禁入），id-only 加法条目被静默忽略（rows 33 实证）。
用户裁决走方案 C（模板物化）+ 存量全量调整。

## 存量事实（先查后动）

- 13 个普通 Agent 的 agent.patch.yml **已含** collab-tools（历史行集点名）。
- 仅 4 个预设缺失：__standard__ / __creator__ / __abap_dev__ / __dsh_minimal__。
- 因此落点 = 3 个通用模板 rows + 3 个存量预设 patch；dsh-minimal 保持极简 2 件工具面（不加入，负差量语义）。

## 改动面

1. `packages/ac-host-rows/templates/{standard,creator,abap-dev}/config.json`：rows 增 `collab-tools`（issue-tools 之后）——
   模板物化口径：新建 Agent 从模板创建即默认装备（menu-assembly §2.2 模板物化）。
2. 存量预设 patch：`workspace/home/agents/{__standard__,__creator__,__abap_dev__}/agent.patch.yml` 补 collab-tools 定义——
   经装配链同源写入面 `writeAgentPatchV3At`（原子写 + 一代备份 + src-fingerprint = 8c2f8173d281e534）。
3. `__dsh_minimal__` 不动（极简模板的工具体量是产品定位，非遗漏）。
