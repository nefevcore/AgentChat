# cr-1098 修复 cr-1097 GeneralSection 误删池域 + 连接池数据恢复

## 现象
2026-11-15 09:22 起所有壳 LLM run 收束 error：`model "mock" 无法路由到任何 provider（无已注册 provider）` / `未注册的 llm provider "zai-coding-cn"`。

## 根因
cr-1097 新增的 GeneralSection（开发者模式开关）保存走 `config/save` 且 payload 只携 `{ settings }`。而 `config/save`（ac-host-webui config-face.ts saveConfigDomains）是**白名单域全量 replace 语义**——payload 缺的白名单域一律 `face.delete`。09:19:49 用户切换 devMode 开关即把 `llmProviders` / `searchProviders` 整域从 config.json 删掉（凭据库 credentials/ 未受影响）。cr-1097 注释「携原 settings 对象整写防覆盖兄弟键」是对语义的误读。

## 修复
- GeneralSection.vue 改走 `config/set` 单键写（新助手 `saveSettingsDomain`，api.ts）——只动 settings 键，兄弟域零触碰。
- 顺手：GeneralSection 三处冗余可选链 lint 修正；cr-1097 漏更的 `ac.faces.web.seats` 补 `settings:section`（seats-gate 门红修复），webui.yml 重生成。

## 数据恢复
- 恢复来源：usage 聚合（在用模型 deepseek-flash / glm-5.3 / glm-5.3-flash）+ conv-settings（provider 归属）+ 凭据库名册（POOL:DEEPSEEK/GLM/GLM-MAX/ZAI-CODING-CN，SEARCHPOOL:DEEPSEEK/DS-SEARCH/MAIN）。
