# cr-1051 subagent await 引导修正：等待动词改查询语义

- 日期：2026-11-13　状态：done　标签：#subagent #prompt

## 动机

Agent 调 subagent await 时长时间阻塞等待（大 timeout_s 干等）——引导不足：原描述把 await
定义为「等待并取当前结果」动词，running 态 hint 还教「可加大 timeout_s 续等」。而机制上
spawn 不带 wait_time 即转后台，子完成后终稿自动回投发起会话——await 本应是短超时查询/收取，
pending 即收手转做其他工作。

## 改动面

1. `packages/ac-shell-subagent/src/service.ts` 主描述 await 段：等待→短超时收取（本质查询动作），
   加「勿设大 timeout_s 长阻塞干等：后台子完成后终稿自动回投，拿到 pending 即收手」。
2. 同文件 timeout_s 参数描述：同口径修正，给出建议量级（小正值如 30-120）。
3. 同文件 running 态 hint（childBriefOf）：删「可加大 timeout_s 续等」，改「等完成通知自动到达，
   勿持续加大 timeout_s 干等；期间推进独立工作」。
4. `packages/ac-run-code-core/src/index.ts` run_code SDK 提示词：spawn 补「不带 wait_time 即转后台，
   完成终稿自动回投」；await 由「阻塞收结果」改「小 timeout_s 短查取结果，pending 即收手」。

同步 `node scripts/gen-tool-catalog.mjs` 重新生成 tool-catalog.json 投影（工具描述源变更）。
