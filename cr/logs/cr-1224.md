# cr-1224 sandbox-core bash-scan 载荷剥离（ISSUE-17）

## 根因
`stripHeredocPayloads` 只剥 heredoc/here-string，引号内 `node -e` / `python -c` / `pwsh -Command` 载荷不在剥离范围（src 注释自认已知残留）→ 载荷里的 JS 正则字面量（`/^>/.test(s)`）与裸除号被 Unix 绝对路径启发式误判拦截，白名单指引对非路径 token 无意义。

## 修法（fail-closed 保持）
- 新增 `stripInlineCodePayloads()`：三种引号载荷形态替换为 `<code-payload>` 占位（匹配失败保留原文 → 只可能多拦不可能漏拦）。
- 裸 `/`（除号/撕裂正则片段）不判路径——路径至少含一个非斜杠字符。

## 验证
- 新用例：正则字面量/除号载荷放行；载荷外越界路径（`node -e "1/2" && cat /etc/passwd`）照拦；无引号形态原文受检。45 全绿。
