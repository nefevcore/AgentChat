# cr-1049 工具调用模式注册制（批 2 主体）

## 动机

- 目标：「为未来更多调用模式留扩展缝」+「模式完全自主装卸（判定词汇随行退场）」。
- 前形态：injection:'mode' 工具自荐标记 + 核心包硬编码 tc-programmatic 分支——工具反向依赖模式词、模式判定词汇住核心包不可装卸。
- 三轮方案推演（injection 改形状 → 模式 entry 点名 → 模式嵌 tools → discover 谓词 + 两步投影）：最终裁决 = 工具侧 discover 发现谓词（可选、缺省 true、纯函数）+ 投影核心两步化（①发现 ②处理）+ ctx.agents.registerToolMode 纯元数据注册表。模式与入口工具的关联知识唯一落点 = 入口工具自己的谓词；注册表不点名工具、不含行为。

## 改动面

- ac-tools 契约：删 injection；增 discover?: (ctx: ToolFaceContext) => boolean + ToolFaceContext（纯数据：toolMode/agentId/conversationId）。
- ac-agents-core：ToolMode 开放词（'tc-none' | 'tc-base' | (string & {})）；ToolModeDef 契约（id/label/description 纯元数据）；patch-doc 'tool-mode' 与 AgentProfile 'tool-mode' 开放为 string。
- ac-agents：discoverTools（发现步——谓词求值，throw 按 false fail-closed）；narrowToolsByMode 两步化新签名（baseFace/discovered/defs/mode——扩展档取 discovered 中 discover 在场者，入口集空回退 baseFace，cr-1021 语义）；AgentsService.registerToolMode/listToolModes/isRegisteredToolMode（fiber 归属随行回收）；isModeToolFace/widenToolsForGating 载荷换 discover。
- ac-shell-rows shims：AgentsShim 补同名注册面（垫片是壳内 ctx.agents 实现，boot 先于行集装配——run-code inject agents 解析恒达）。
- ac-run-code（狗粮验收）：apply 双注册（registerToolMode tc-programmatic 纯元数据 + tools.register run_code 带 discover 谓词 face => face.toolMode === 'tc-programmatic'）；tool.ts 子调用投影排除面 injection→discover；prompt.ts SDK 投影入口集判定同迁。inject 增 agents。
- ac-shell-conversation llmToolFace：两步投影（发现步→行集∩发现→处理步；扩展档无入口回退 baseFace + warn 留痕）。
- ac-host-webui face-shell：估算面同构两步化；静态 catalog 携带 discover:false 布尔标记（gen 链投影：有谓词 → false）。
- ac-collab-tools 分派面过滤、gen-tool-catalog 投影、conv-settings toolMode 键（enum → pattern /^tc-[a-z0-9-]+$/ 开放词，注册表校验在投影端兜底）。
- ac-shell-subagent inherit：形态合成语义不变（run-code 行 id ∧ 父形态），标注单模式特写边界（第二模式行出现时通用化）。

## 裁决记录

- discover 缺省恒 true（发现机制通用，非模式标记）；「扩展档只保留显式声明者」是处理步通用规则，零模式特有分支。
- 入口不经行集收窄（原 mode 工具语义：行在装即合成——编排壳粗信任由子调用细信任实现）。
- 副作用清单：写「条件门控但非模式入口」的 discover 须显式含模式条件，漏写则扩展档下被当入口保留（JSDoc 契约，作者全责）。
- 词校验宽松化：写入面 pattern 校验（tc- 前缀），未注册词由投影回退 + warn 兜底——避免 conv-settings 跨进程查注册表。
- 批 3（后置）：UI 词面动态化（AgentPane/ChatInput 三档硬编码 → web-api tool-modes 投影）。
