# cr-1316 historyRowToChatMessage 工具行三键透传（P3-3 并轨收尾）

- 日期：2026-11-25 · 状态：done
- 分析基线：会话 01a21179（同上，问题 2）

## 现象

run_code subcall（call_xxx#N）刷新后前端平铺卡无法查询工具调用参数：
edit diff / write 预览 / read 路径 / pwsh 命令行全失效；缩进样式（视觉归属
run_code 程序卡）同失效。

## 根因

subcall 名/参全文内联在 step/tool-call-result 行（D-1 设计——行本身不缺）；
foldStepsOf 读侧正确注入聚合步 toolCalls；toHistoryMessages tool 行正确投
subcall + arguments 键；**historyRowToChatMessage（feed.ts，cr-1283 转换器
并轨产物）映射体不消费这两键**——HistoryRow 接口声明了（L974-977「词汇如实
声明」）但透传面走散。独立 tool 行还漏投 durationMs（历史工具卡耗时）。

## 修

- feed.ts historyRowToChatMessage：补 arguments / subcall / durationMs 三键
  透传（HistoryRow 补 durationMs 声明）。
- historyApi.ts toHistoryMessages tool 行：投 durationMs（步行内嵌条目原有，
  独立行漏投）。

  直调字符串参数 / 端到端（toHistoryMessages → 转换器参数不丢）。10/10 绿。
- ac-client-ui-conversation 全包 400 例绿；webui:typecheck ✓ + 双构建配对（build:channel 30 包 + webui:build）✓；全量 unit 3643 例（唯一失败为无关并发超时，隔离绿）
  （前端行 client 面）。
