# cr-1332 IM 白名单方案实施（delivered 投递标记行集）

- 立项：cr-1332 2026-11-26 方案裁决（排除法 → 白名单——用户裁决：新机制类型缺省不打标不进 IM，封闭集合零长期维护）。
- 交接档：docs/design/webui/im-delivered-flag-handoff.md（事实清单与实施入口）。

## 动机

dual-view P2 的 IM 视图排除法（imRow 逐类剔除）是不断增长的开放集合：每引入一个新机制类型都要追加排除判据（cr-1331 三次追加即实证）。白名单反转判据：写面打标 + 读侧取行集。

## 裁决

- **终稿打标**（用户裁决 2026-11-26）：打，但值用独特标记 `delivered: 'final'`（区别于通道投递行的 `delivered: true`）——便于观察打标/不打标的效果。
- **词汇**：`delivered?: boolean | 'final'`——入站/出站通道投递行 `true`；终稿行（origin 门控：`viewer`/`interaction`）`'final'`；机制信封、notice 转投通知、第三方写面缺省不打标（opt-in，宁漏不误）。
- **读侧**（会话级切换，零迁移）：im 档先探测会话内任一行带标 → 白名单模式（`delivered === true || === 'final'` 直取，error 红条随终稿同门控打标故可见）；零标存量会话 → 回退排除法（imRow——cr-1331 行为分毫不变）。
- **steer 注入行（风险 1 裁决）**：不注入白名单——现状 imRow 剔 context 行（busy-steer 注入卡 IM 不显示），白名单维持同语义零回归。终稿回信链完整承接 agent 回复。
