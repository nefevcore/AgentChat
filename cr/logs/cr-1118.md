## 动机（事故复盘）

news~news（news 自会话桶）上下文冲破 LLM 上限（请求 148.8 万 > 模型上限 104.9 万，run 全部 HTTP 400），
但 25 天（2026-10-22 起）无任何归档触发。根因：**cr-1033（d0b0d3d0，2026-11-12）把 `archive` 行
从 shell.yml 骨架移入 ac-shell-rows 包 ac.rows 能力行**——能力行须显式进 Agent 菜单才装配，而存量
Agent 的 agent.patch.yml 均无此行（archive 原是骨架行，不在任何 patch 定义里），迁移「指纹零漂移」
恰恰意味着没人接住它 → 全系统 14 个 Agent 的壳都无 ArchiveShellService（boot-graph 实测全缺），
阈值检测从未注册。同期 news 的 30 分钟 timer 每轮追加 ~18-49KB 记忆快照 inject 行（35 条 ≈ 49 万
tokens）只进不出，4 天冲破模型上限。
