1. 写入序 = 换名 → 转 .migrated（反序会在中断窗口真丢崩溃孤儿 run 步；正序中间态仅多 inject
   事件副本、fold steps 走段行 aggregated 优先——消费面零命中，伤害最小序）。
2. 对账判据从 M-A 测试提升库面（判据单源——工具 + 测试共用，避免双实现走散）。
3. speech/contexts + run events 用多重集比对：v2 输出行序按 ts 全序重放，journal 落盘延迟的
   inject 迁后插位前移（ts 纠偏）；语义内容多重集恒等才是判据面（语义重排接受）。
4. cr-978 裸行（缺 message_id/timestamp）迁移后行面键缺席、facts 层 String 兜底空串——
   读侧既有容错等价消费（恒等携带，不在迁移边修数据）。
5. 真实数据根实测驱动的三处修正：journal 行缺 ts（cr-697 前）→ 判据 ts→0 归一；
   群转发 run-settled 裸行多条空 messageId → 多重集比对；压缩 run 端序覆盖 → 边复用真实收束。
