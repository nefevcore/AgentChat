# cr-1319 用户本地行出生带键（直播键落位补齐批 B1a）

- 日期：2026-11-25 · 状态：done · 引用：→cr-1318（判读定性 tgf rows=1 真凶 = 本地直发行）→cr-1286/1289（键控拆轮/直播键驻留）

## 根因

sendMessage 本地乐观行 id = uid('user') 随机值、无 turnId——直播期用户行是键缺席域（cr-1318 判读实锤：
tgf rows 增量全部来自此类行）。协议事实：落盘 message_id = 客户端铸造的 requestId（deliver 幂等键）——
本地行零协议改动即可出生带键。

## 修

- chat-core.ts sendMessage：rid 先铸后用（提升到 busy 分支前）——本地行 `id: rid, turnId: rid`，
  deliver 同一 rid（单源）。排队路径（queue）本地无行，rid 仍作投递幂等键；steer/appendOwnSteered、
  showOwnEcho 回显行不伪造键（无权威身份来源——宁缺勿错，judges 兜底到收束换身）。
- 刻意不设 persistedMsgId：本地行无权威边界（deliver 失败不该带分支按钮操作面——types L197 语义）。

## 对账核验（换身键恒等）

- 收束重拉首屏 = 整体替换 + anchor 内容比对保护：incoming 落盘后本地行随 existing 丢弃、权威行
  （message_id = rid、turnId = rid——fold 投影用户行 turnId = message_id）换身——键值恒等，
  轮边界不跳变；mergeHistoryPage 双键去重不涉本地行（无 persistedMsgId），无双投路径。
