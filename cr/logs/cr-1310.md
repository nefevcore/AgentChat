# cr-1310 构建面 external 根修：共享面相对引用链路径归一外部化

> 2026-11-25 · #render-pipeline · 前序：cr-1300（残留实例收口记录）——渲染管线计划 §八/9 开放项的治本落地。

## 现象与根因

三例同族（frameScheduler / feed-core cr-1296、fallback-probes cr-1300）：build-channel 的
rollup external 按说明符字面匹配（isExternal：HOST_MODULE_SPECS.some 前缀比对），
通道包内部相对引用链（feed-core.ts → ./feed.ts → ./fallback-probes.ts）解析后是绝对路径，
永不命中字面清单 → 共享面模块被内联成 bundle 副本，单例语义失守（stats 分裂 / 双 rAF 链 /
计数两份）。cr-1300 修复后仍残留内联副本（死代码——运行时执行种子实例）。

逐例入清单 = 治标（每新增一个单例模块都可能漏）；本批治本。

## 修法：resolveId 路径归一插件

新增 apps/ui/scripts/shared-externalize.ts：

- 索引：HOST_MODULE_SPECS 深词（ac-client-(ui|theme)-<pkg>/client/…）→ 共享面源文件绝对路径
  （正斜杠归一形）；/client 裸词形映射到 client/index.ts（exports 解析目标）；双词形同文件
  取 explicit 长词（确定性）。源文件缺席 = 说明符漂移，import 即 fail-loud。
- 插件：enforce:pre 的 resolveId——相对引用解析后路径命中索引 → 归一为宿主模块表说明符
  并返回 { id, external: true }。三重效果：external 直标（不经 isExternal 字面面）；
  产物 require 词 = 归一词 → 运行时命中 module-system 种子①支（宿主实例）；纯度门
  同词闭环（残留裸词 ⊆ 宿主模块表）。
- 挂载位：build-channel 第二遍（isolated 自含档不挂——沙盒独立模块表无种子面，归一即断链）；
  第一遍是词收集裸构建面不挂（挂了会把自包深词混进 globalRequires 对账集合）。
- Windows 词形：vite/rollup 模块 id 正斜杠形 vs node:path 反斜杠形——两侧一律 normPath 归一
  后对拍；repoRoot 去尾斜杠（URL 相对目录解析带尾斜杠——实测踩过：前缀守卫恒 false、
  插件整体静默失效，纯函数用例全红暴露）。

配套：

1. chatOps.ts 入列共享面（cr-1300 审计残留实例——chatPresence 存在集合 / historyCursor
   分页游标均为模块级单例；调用方原全在共享面故运行时一致，任何非共享模块接入即分裂）：
   shared-modules.ts（69 键）+ host-module-table.ts（78 键）同步增项。
2. viteCommon 死代码删除（build-channel.mjs cutover 前遗留——es 档构建配置块全仓零调用，
   cr-937 排查时已确认死代码身份；esbuild 降级注释迁移到第一遍 build 块保释史）。

## 测试锁（apps/ui/tests/shared-externalize.test.ts）

- 纯函数面：命中（feed.ts / chatOps.ts 相对链）→ 说明符；未命中 / 裸说明符 / 仓库外 importer /
  importer 缺席 → undefined；Windows 反斜杠 importer 归一；注入索引独立性（specs 参数——键
  契约 = 正斜杠绝对路径）；resolveId 返回形 { id, external: true }。
- 实构建面：微型 vite 构建（sandbox/ 临时目录）复现根因链——entry 相对引用共享面真身文件，
  断言产物 import 词 = 宿主模块表说明符且实现体特征词（directDialog）不在产物中（不内联）。

## 后继语义（对共享面维护的影响）

- 共享面新增模块只需入 shared-modules.ts + host-module-table.ts 两处清单——相对引用链随
  归一自动外部化，不再需要「相对引用方也要字面引用」的隐式前提。
- 「被引用的单例状态模块必须同列共享面」教训（cr-1300）仍然有效——共享面判断仍看状态
  单元本身；但内联副本层面已由插件构造性消灭。
