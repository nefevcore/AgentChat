## 动机

timer-v3 设计（cr-1161）§十实施顺序的「再下一批」：ac-source-core + fs-source + stale / pull 兜底——条件唤醒（source 触发）半边上线。此前 source 触发词汇已入契约（cr-1164）但运行时无源注册面，纯源条目一律 dormant。

## 改动面

- **ac-source-core（新建包）**：
  - 物化纯函数 `materialize.ts`：`<dataRoot>/exports/<source>/<view>/{rows.jsonl,meta.json}`；快照 diff（新增/变更各一行，删除不记——v1 边界）；seq 单调；`MAX_SOURCE_ROWS` 10k 行滚动（rows.jsonl → .old 覆盖保留一代）；零变化也刷新 generatedAt（活性心跳——stale 判定锚）；`readRowsSince` 跨代读；meta 缺席/损坏 = null（源不可用）。
  - 事件目录 `events.ts`：`source/updated { source, view, seq }`（emit / host scope；一次物化一个事件——批量不逐行）。
  - **fs-source 行**（Service 形态，`static inject = ['timer','config']`）：按 cadence 扫描 config `source.fs.roots`（`{id, root, glob?}`）→ 快照 diff 物化 → 变化即 emit；glob v1 = 后缀匹配（`*.md`）；config/changed 热重载 roots（增删源不重启）；无 roots = 零定时器。
- **timers-row 源触发运行时**：
  - push 分发：构造器订阅 `source/updated` → 按 entriesByAgent 匹配订阅条目 → `readRowsSince lastSeq` 增量取行 → matchRow 求值（match 缺席 = 新行即命中）→ `fireSource`（复用 dispatch/gates/记账/审计/until 链；cause 'source'）。
  - cooldown 条目级节流：窗口内不投但 lastSeq 照常推进（判断不丢，投递节流）；缺省 5m；stale 唤醒也吃 cooldown（缺省 30m）。
  - pull 兜底：仅源条目在场时起 interval（10s 地板防风暴）——扫 meta.seq 比 lastSeq 推进多即当一次事件；顺带 staleSweep（generatedAt 超 staleAfter → on:'stale' 条目唤醒）。
  - dormant 语义换轨：源已物化（meta 在场）即活——纯源条目不再恒 dormant；源行缺席（无 meta）→ dormant 'source-unavailable'，事件到达时 re-arm 解除。
  - lastSeqByEntry / cooldownUntil 随 forget() 单点清理；stopAll 扩展停源运行时。
- **装配面**：host.yml +fs-source 行（版本戳 4→5）；ac-host-rows HOST_ROW_FACTORIES +fs-source（`c.plugin(FsSourceService, o)`）；rowOptionsFor +dataRoot 注入；ac-host-rows 依赖 +ac-source-core；gen-row-catalog 重生成（host 27→28 行）。
- **文档面**：timer-v3.md 状态行补「采集层 cr-1165 已落地」；host-shell-row-manifest R1 27→28 行（数据服务 6→7，timers 行补源触发说明 + fs-source 行新增）。

## 裁决与踩坑

- **cr-282 start-time 软取坑现世报**：fs-source 首版是函数插件 apply 内 `ctx.get('config', false)` + `ctx.interval`——cordis 裸 Context 无 interval/timeout（它们是 cordis-timer 服务激活后挂上的扩展），start-time 软取撞 undefined。修正 = Service 形态 + `static inject = ['timer','config']`（fiber 依赖等待保证构造期就位）。
- **cordis apply 返回值即 effect**：工厂 `() => ({ apply: (c) => c.plugin(FsSourceService, o) })` 的箭头隐式返回 Fiber 对象 → safeCollect "Invalid effect" 五连炸。apply 必须语句体丢弃 plugin() 返回值。
- cooldown 测试时序：300ms cooldown 与 wait(300) 同值竞速——放宽到 2s 窗口消除边界歧义。
- fs-source glob v1 边界：只后缀匹配（`*.md`），前缀/字符类不进 v1（防词汇表癌变——同 timer match v1 精神）。
