# cr-1283 P3-3 转换器并轨（session-render-pipeline-plan §四 P3-3）

> 2026-11-24 · #render-pipeline #frontend · 前置：P3-2（cr-1282 keyed store）

## 动机

三份视角转换器（historyMsg / pairMessage / groupMessage → ChatMessage）对同一投影行各写一份字段透传面，长期走散：

- pair 视角漏 stepId/runId/seq/anchor/persistedMsgId/injectBytes——P3-1/P3-2 的键控收敛在只读视角（矩阵格/子代理视图）失效；
- group 视角漏 aborted/apiMs/apiCompletion/toolName/注入面；
- group id 全随机（每次刷新 Vue key 全变）；run-boundary.test 还藏第四份本地小转换器 toChat。

根因：转换逻辑按视角复制而非按行词汇单源。修法 = 并轨为单份 `historyRowToChatMessage`（feed.ts），三视角仅传视角参数（idPrefix/fallbackAgentId），键族全量透传 + HistoryRow 类型词表锁定投影输出词汇。

## 裁决

- **群链仅转换并轨、不动投影扩字段**（§八-1 R2 搁置——用户裁决 2026-11-23）：group/history 仍只投 id/from/content/at(+steps/attachments)；单源转换器对投影扩字段零改动即透传（HistoryRow 词表声明到位，键到场即消费）。并行 run 时序穿插的跨流 run 排序语义未解决前不扩投影。
- **persistedMsgId 优先级 = grpAnchor ?? messageId**：群分区语义下群读位键（去重键）优先；两键生产中从不同时在场（词汇不交叉：group 行带 id 无 message_id，session 行反之）。
- **群行渲染 id 不复用行锚**：同 record steps 展开行共锚（persistedMsgId 同值去重），渲染 id 若复用锚会 Vue key 碰撞——无 sid/message_id 时走前缀随机（不共锚）。
- **single 视角零参数**：投影行恒带 message_id（id 恒稳），无需 idPrefix/fallback；pair 视角 fallbackAgentId = 对端端点；group 视角 idPrefix='grp'。
