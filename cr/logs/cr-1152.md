
# cr-1152 · unread 功能面暂时下线（cr-1146 消费面全停）

> 性质：功能下线（性能根因退避）｜状态：doing｜2026-11-17
> 关联：→cr-1146（服务端权威源实施）、→cr-1151（批量对账 SQL 聚合根修——修完仍 1.3–2.1s）

## 动机

cr-1146 未读服务端权威源在 cr-1151 根修后仍有不可接受的性能面：启动期
`session/unread` 批量对账 1.26–2.09s（1335 会话），且入账路径每写一行都
承担 speech/claim/fact/anchor 四列谓词落值成本；首屏旁带 unreadOf 全行集
直扫叠加。单线程宿主 + 前端 init 必发批量对账——启动期 RPC 饥饿的形态
只被缓解未消除。裁决：整个消费面下线，重新设计后再回来。

## 改动

### 服务端
- `ac-host-webui/src/web-api.ts`：`session/mark-read` / `session/unread` 两个
  RPC 注销；`session/history` 首屏 `unreadSide` 旁带退役；`SessionIndexFace`
  窄接口 `refreshUnread`/`unreadCount` 两成员撤（消费方消失）；ac-core-utils
  未读词汇 import 全撤。
- `ac-host-rows/src/groups-row.ts`：`group/history` 首屏未读旁带退役。

### 前端（ac-client-ui-conversation）
- `feed-core.ts`：读位机制整块退役（`convKeyOf`/`readAnchorOf`/`_readIntent`/
  `flushReadIntent`/`applyAuthoritativeUnread`/`reconcileUnread`/
  `dialogIdOfConversation`——100 行）；`clearUnread` 收窄为纯本地清零；
  session/group 首屏旁带消费、init 批量对账、导出面 `reconcileUnread` 撤。
- `historyApi.ts`：`fetchGroupHistory` 返回型 `unreadCount` 透传撤。
- 现行语义：live 帧锚定计数（bumpUnread，cr-1139）+ 进入即清——纯本地态，
  刷新后徽章归零，页面关闭期间的产生不跨启动补计。

### 前端状态清理（批 2，用户要求「顺手清理」）

cr-1146 消费面下线后，前端仍留一整套纯本地徽章机制（cr-1139 锚定计数）。同批全撤——不留死代码，重设计按服务端原料重建：

- `feed-core.ts`：`DialogFeed.unread`/`unreadTs` 字段撤；`bumpUnread`（含 `_unreadAnchors` 锚表 + `UNREAD_ANCHORS_MAX`）、`clearUnread`、`pruneSingleUnread`、`getUnreadCount`、`unreadAgents` computed 全删；四处增量点（showInbound 私信 / run\/settled 收束 / group\/message-posted 群发）与 `setActiveGroup`/`setActiveSingle` 的进入清零调用同步撤（notify 门控改为纯 `viewerRelevant && 非活跃`，语义不变）。
- `chat-core.ts`：`clearUnread`/`getUnreadCount` 导出面撤。
- `useUnreadBadges.ts`（聚合单源）：整文件删除；`App` 共享模块表（`apps/ui/client/shared-modules.ts` + `scripts/host-module-table.ts`）同步摘除。
- 徽章 UI 删除：`AgentList.vue`（Agent/群行角标 + `unreadCountOf`/`unreadLabel`）、`SessionList.vue`（搜索态/树态行角标）、`ActivityBar.vue`（两按钮聚合徽章 + `.unread-badge` 样式）、`MobileTabBar.vue`（tabs badge 字段 + 角标 + 样式）。
- 契约面：`ac-client-runtime` `SessionsClientFace.pruneSingleUnread` 撤 + conversation 行 client 实现撤 + singles 行调用撤（孤儿未读清理链随徽章一并消失，无消费方）。
- 测试面：删 `unread-anchor.test.ts`（cr-1139 锚定计数回归）、`unread-settled.test.ts`（cr-1057 收束增量）、`unread-enter-clear.test.ts`（进入即清）；`chat-ops-regenerate`/`draft-single` 桩中未读字段同步清。

净效果：feed-core 2854→~2790 行，五个组件去掉全部未读 UI，未读在界面上彻底不可见。
