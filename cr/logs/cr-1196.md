# cr-1196 check 路径劝告降噪（v3.2）

## 动机

`cr-git check` 输出 85 处「路径未命中」劝告（不阻断）。实测分类：正则吞字误报 14 / git 历史存在 31 / gitignore 覆盖 4 / 真残余 39。索引 append-only 禁手编——历史欠账的消解只能住守门工具侧。

## 改动面

- `packages/ac-cr/src/cr-git.mjs`（正本）：
  - PATH_RE 收紧：`(?:[\w.@-]+/)+[\w.@-]+\.(?:md|json|ya?ml|ts|mjs)`——消除中文/箭头/全角括号粘连误报；`./` 前缀归一。
  - check 豁免链：worktree → git 历史（`log --all --name-only`）→ gitignore（`check-ignore --stdin`）→ 白名单 `cr/path-allowlist.json`；git 调用失败 fail-open。
  - 白名单双反报：不再触发劝告的条目反报「可删除」；新 CR 命中白名单路径且号不符反报「过时」。
  - `doSync(rebuild, persist)` 参数化：check 懒校验走内存态（cr-1136 从部署副本回植包源码）。
  - 新 `selftest` 子命令：sandbox 临时 git 仓六组断言（豁免链四层/正则收紧/劝告不阻断/白名单双反报/正则收紧/零写副作用/sync 落盘）。
- `cr/path-allowlist.json`（部署侧新文件）：39 条存量白名单，全部带登记 cr 号与 reason（旧布局/意图路径/运行期数据/并列用词粘连）。
- `cr/`（init 重跑升级部署副本，台账未触碰）。
- `docs/design/meta/cr-tool-v2.md`：补 v3.2 裁决节。

## 裁决

- 豁免链每层对应一类结构性根因：历史存在 = 登记时真实后被移动/删除；gitignore = 本地数据面（不告）；白名单 = 显式登记的意图路径/历史欠账。
- 白名单带「过时反报」防腐化：条目不再触发即反报删除；新 CR 蹭旧白名单条目反报重验。
- check 保持零写副作用（cr-1136）：懒 sync 走内存态，投影落盘走显式 sync。
- 别项目复刻白名单需重新按项目实弹生成（39 条按 AgentChat 帆布生成）。

## 验证

- `node packages/ac-cr/src/cr-git.mjs selftest` 全绿（6 组断言）。
- 实弹：`node cr/cr-git.mjs check` 劝告 85 → **0 处**，无阻断项。
- 验证阶梯：`pnpm typecheck` / `pnpm check:deps` / `pnpm test:unit`（452 文件 3357 用例）全绿；eslint 面为 .mjs 全仓既有豁免形态（非本次引入）。
