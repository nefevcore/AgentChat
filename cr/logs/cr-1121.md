# cr-1121 host-face 宿主契约真动态化

> 状态：doing（2026-11-16 登记实施）
> 承接：cr-886（host-face 懒装配）→ cr-1114（承诺面 + 工具源统一）

## 动机

cr-886 的宿主契约是写死清单（tools/sections 常量 + 宿主执行面 if-chain）：
新增宿主远程能力要同时改 core 常量与宿主行两处，第三方宿主行无贡献入口。
真动态化：契约 = 装配期注册面聚合（插槽-插头——host-face 是插槽，贡献行是插头）。

## 改动面

1. **core 词汇**：`HostFaceContract` 增段 `promise?: boolean`（恒真静态段标记）；
   新增 `HostToolExecutor` 类型；promise.ts 常量（HOST_FACE_TOOLS/SECTIONS/
   PROMISE_SECTIONS）整体退役。
2. **注册面**：`ac-host-face` `HostFaceRegistry`（Service 键 `hostFaceRegistry`）——
   `contribute(caller, key, {tools, sections, executor})` 注册即归属（cleanup 挂 caller
   fiber effect）；discover = 现算聚合 + 契约缓存落盘；execute = 按名路由贡献行。
3. **内置贡献行**：timer-face（timer 工具 + GUIDELINES_TIMER promise 段）/
   profile-face（update_agent_profile）——执行面自 tools.ts 搬家，语义原样。
4. **契约缓存**：`meta/host-face-contract.json` 宿主单写壳只读——壳 boot 静态面
   数据源（cr-1114 的 core 常量直取退役；冷数据根盲窗如实，prepare 缝对账收敛）。
5. **host-rows**：timers-row 的 `currentHostFace().invalidate()` 退役（契约恒基线，
   timer schema 不随条目变；list 恒现值）；ac-host-face 移入 dependencies。
6. **行集**：host.yml +timer-face +profile-face（ac-base-version 3→4）。

## 语义裁决

- TERMINOLOGY / GUIDELINES_COLLAB 宿主补位段退役：collab 语义段与壳内
  ac-collab-tools 本地 owner 绑定，宿主不再兜底（壳内行缺席 = 段缺席，本地语义自洽）。
- timers 条目变更不再 invalidate：契约内容恒基线，动态面（条目）本来就不在契约里。
- facts 恒宿主全集：数据根直读能力不随行集摇摆。
