# cr-1344：user 域账本对称化（cr-1343 计划实施）

> 2026-11-26 · 批次 A-D 全落。计划档：docs/design/assembly/user-domain-ledger-plan.md。

## 动机

agent→user 投递落 sender 的 agent 域出站行（域与归属错位）。用户两原则裁决：
single-writer（消息发给 user → user 桩写入自己的账本）+ 读时投影（viewer 可视面从多域账本并读合成）。
sender 工作记忆由 tool 对承载（foldSession + foldLlmReplay 实证）——出站行无需轻量回执替代。
