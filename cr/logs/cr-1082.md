# cr-1082 access 轴整体退役计划成文（access-retirement-plan）

## 动机

- 用户裁决：access 本质是 approval 操作——base 实为 sandbox 回退词（危险操作询问、无人按配置拒/过），full 即全通过。整体退役。
- 勘察实证：① 执行链对 sandbox-access 零分支（所有边界判定只区分 full/非 full——sandbox 是安慰剂档）② 会话键 857 个全 full（sandbox=0 base=0）③ ToolCall.access 合法来源三处中 full 的真实发放者就是审批注入（contract.ts）。

## 计划要点

- **核心行为变更**：设置链 allow 路径补 full 注入（「通过即 full」）——审批轴成为 full 唯一发放者。现状 allow 放行不注入 full（沙箱照拦），统一后与弹卡批准同权。
- Agent access/tier 字段迁移：4 个 full Agent → permission-gate onAsk=allow（news 现场形态）；8 个 sandbox 等价无配置，清字段。
- 词汇两态化：AccessLevel/ACCESS_RANK/effectiveAccessOf → isFullAccess 布尔判定；deliver 继承/剥除/不降档链与 subagent inherit.access 整段退役。
- 与 conv-scope-plan 接续：先落批 1（effective 读取面）再拆继承链；存量键清理两计划合流一脚本。
