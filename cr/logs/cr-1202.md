# cr-1202 timers-row 全局设置层死键修复（agents.settings → settings）

## 动机

用户裁决：时区作为数据根 config.json 配置项，后续前端设置页可调。
探查发现链路三段中两段已就绪：
- 词汇已立：cr-1053 `settings.timers.timezone`（config.json 全局默认层
  settings 域，ac-agents settingsOf 两层合成）；
- 前端写面已通：cr-1199 注册化后 `settings` 域在 configDomains 白名单
  （ac-client-ui-settings 注册）——config/set 现在就能写；
唯一断点：timers-row.layerOf 读 `config.get('agents.settings')`——死键
（config.json 无 agents 顶层键；主线合成口读顶层 'settings'，现役数据根
与 settings-of.test.ts 播种均为此形态）。cr-1147 引入时键名漂移，无
timezone 测试覆盖 → 全局层时区/节假日配置对 timer 触发恒不生效。

## 改动

1. `packages/ac-host-rows/src/timers-row.ts` layerOf：
   `get('agents.settings')` → `get('settings')`，附注释（cr 号 + 死键
   来历 + 现查语义——每现查不缓存，config/changed 后新值即生效）。
2. `packages/ac-host-rows/tests/timers-row.test.ts` 新增锁定用例：
   - config.json `settings.timers.timezone: Asia/Tokyo` → tzOf('alpha')
     生效；
   - 死键形态 `agents.settings.timers.timezone` 写盘不得生效（防回归）；
   - `config.set('settings.timers.timezone', …)` 现查语义——set 后立即
     可见（前端改配置即生效，无需重启）。
