# cr-1052 时间出口统一收敛

- **日期**：2026-11-13
- **动机**：全仓时间戳排查发现键派生层口径分叉——存储层（ledger）统一 UTC ISO 无问题，但「从时间戳派生日/月键」处本地/UTC 混用，同一数据两种时区。
- **改动面**：
  1. 新增 `ac-core-utils/src/time-keys.ts`（utcDayKey/utcMonthKey）——日/月键派生全仓单源；
  2. `ac-usage`：dayKeyOf 改 UTC（原本地 getter 与流水文件名 UTC 切片矛盾——凌晨时段同一行写「昨天」文件计入「今天」聚合）；流水文件名两处改走 utcDayKey；
  3. `ac-relay-server`：房间流量日键 dayKeyOf 收口 utcDayKey（修不补零 + 本地漂移）；download-gate.ts 月键改 UTC 收口 utcMonthKey；package.json 补 ac-core-utils 依赖；
  4. `scripts/download-gate.mjs`：月键收口 utcMonthKey（与 relay 包内实现同口径）；
  5. 口径声明（不改行为）：host-log/ac-datetime/webui-kit formatRelativeTime/cr.mjs today()（含 ac-cr 镜像）——展示与本地工作流维持本地时区，注释声明；ac-client-ui-usage 测试的 UTC today 补注释。
- **裁决**：
  - 排查期两项误报撤回：ac-memory `date + toISOString().slice(11)` 拼接结果带 Z、合法 ISO 且测试锚定该语义（日期段=参数/时刻=当下 UTC），不改；cr.mjs today() 本就补零，仅声明口径。
  - relay 房间流量重置窗口随之改为 UTC 自然日（公网中继的配额窗口取服务器中立时区，语义更准）；存量房间 dayKey 为内存态，重启即新口径，无迁移面。
  - download-gate 月片文件名随月键实现已有存量：两实现各部署一处、月中间切换无感，不迁移历史文件（跨月自动新片）。
- **验证**：core-utils 新增单测；`pnpm typecheck && pnpm test:unit && pnpm check:deps` + 定向 eslint + 定向 vitest（见登记行尾）。
