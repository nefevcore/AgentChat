# cr-1225 timer 预览 gates + 校验前缀（ISSUE-23③④）

## ③ 预览不应用 gates
- 根因：`previewFires()` 只取时间网格点，完全不评 gates——workday 门条目预览列出周六/周日的触发点，消费方据此误判会真 fire。
- 修：`previewFires` 增 resolver 参数（缺省恒 workday——无 gates 语义不受影响）；提名循环内逐刻度 `gatesPass` 过滤，被挡刻度续推下一刻（SKIP_LIMIT=400 防病态门无限扫描；耗尽 = 该触发器无点，不出列不说谎）。推进只记胜出触发器（consumed map），未胜出者下轮重新提名——与原全局推进语义等价。
- `timers-row.preview` 传 `this.resolverOf(owner)`——预览与运行期 fire 同一节假日表。

## ④ 校验错误前缀
- 根因：timer-face test 分支 catch 统一前缀「when 非法」，但 `validateTimerEntries` 校验整条（gates/until/missed 同走此 catch）——`when 非法：entries[0].gates[].kind 非法` 前缀与字段自相矛盾。
- 修：改「条目非法（未落盘）：」与 set 分支同口径。

## 验证
timer-core 36 全绿（新用例：workday 门三连刻正确跳过周六日；hours 窗外恒挡 → 空列）。
