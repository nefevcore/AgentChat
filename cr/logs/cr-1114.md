## 批 1：正确性修复（2026-11-15 实施会话）

### 事故与根因

timer / update_agent_profile 三面失明（LLM schema / SDK 投影 / 远程段）。根因两条：
1. rowTools 相位错位——boot 一次性回填追不上 cr-886 懒装配注册（prepare 缝）；
   cr-1007「已知行 id 而 rowTools 无键 = 滤除」把整行工具滤掉。
2. 前缀快照相位错位——syncPrefixSnapshot 先于 agentLoop.run() 执行，首 run
   物化正文永远不含懒注册工具；指纹 diff 只通知不重写正文。

### 改动面

- **改动 1/4（spec 下沉）**：HOST_FACE_TOOLS / HOST_FACE_SECTIONS 自
  packages/ac-host-face/src/{tools,sections}.ts 下沉
  packages/ac-host-face-core/src/promise.ts（单一事实源；壳不再依赖宿主行包）。
  宿主行 index.ts 转引 core 导出；sections.ts 删除。
- **改动 2（boot 静态承诺面）**：ac-host-face-client apply 同步段注册代理
  工具——spec 直取下沉常量（零 I/O、零 ipc），execute 内惰性连接（宿主缺席
  = 调用时报可读错误「宿主能力面不可达」，boot 不被阻塞）。
- **改动 3（prepare 缝对账重建）**：registerSectionPrepare 职责收窄——
  discover 契约与在册面 diff：恒等零操作；spec/段漂移或 invalidate 后重建。
- **改动 4（段静态注册）**：HOST_FACE_PROMISE_SECTIONS（壳内恒无本地
  owner——GUIDELINES_TIMER）boot 同步注册；TERMINOLOGY/GUIDELINES_COLLAB
  保持对账补位（本地优先——骨架行先占位会饿死 collab-tools 的 fail-loud
  注册，实测事故后收敛设计）。
- **改动 5/7（rowTools 活查询化）**：toolFaceOf 撤 per-config 值缓存，改
  use-time 现算：options.rowTools（静态对象）→ options.rowToolFace（回调）。
  boot.ts 的 rowToolFace() = listWithOwner() 按 fiber 归属分组 + fiberNames
  桥（行 id ↔ fiber 名）回行 id。shims.ts AgentsShim 同步换源。
- **改动 6（boot 回填退役）**：注册面反查回填退役为 boot-graph.json 审计

- **改动 8（快照漂移升 ③）**：syncPrefixSnapshot 对账分支新增 textDrift
  判据——ptcSdk / tools / sectionTexts 任一漂移 → ③ 重算（与 model/provider
  同通道；SDK 投影字节变 = KV cache 前缀必死，重算白纸无代价）。diff 通知句
  #1（工具集）/ #9（PTC_SDK）随之退役（不可达）。

## 批 2：ToolSource 契约 + MCP 发现缓存（2026-11-15 同会话续作）

### 改动面

- **改动 9（契约与事件）**：`ac-tools/src/contract.ts` 增 `ToolSourceFace` /
  `ToolSource`（bootFace 承诺面 / discover 活发现）/ `ToolSourceDiff`；
  `ac-tools/src/events.ts` 增 `tools/source-changed`（emit，@scope host——
  差异非空才发，消费方无 per-source 分支）。归属词约定写进契约注释：
  `listWithOwner()` 的 owner = fiber 名 ≠ 行 id，行 id 展开靠 boot 的
  fiberNames 桥——不引入第二套归属词汇。
- **改动 10（两源实现）**：`ac-host-face-client` 导出 `hostFaceToolSource(dataRoot)`
  （bootFace 取 core 常量、discover 走 ipc；行内注册仍走同一常量/同款
  client——不新增第二套注册路径）；`McpService` 实现 `bootFace()`（在册面
  投影，零建连）/ `discover()`（sync 后归集）。
- **改动 11（缓存落点）**：新文件 `ac-mcp/src/discovery-cache.ts`——
  `<dataRoot>/meta/mcp-discovery/<def-hash>.json`；def-hash = 服务器定义
  指纹（name/transport/url/headers/command/args/env/insecure 规范化排序
  序列化 sha256 前 16）。原子写（tmp+rename）；读侧损坏/缺席 = null（回落
  冷启动）。data-root-layers §二 meta 内部表已登记（寄居第二层避免顶层
  新目录——doctor 对账面 meta/ 是合法顶层项，无需加白）。注：计划原文
  「doctor 对账面加白」经核无需代码改动——auditDataRootLayers 只扫数据根
  顶层，meta/ 内部不审计；登记文档即合规。
- **改动 12（boot 承诺面）**：`loadCachedFaces()` 在构造器 reconcile 后
  执行——池内 enabled 服务器有缓存即注册代理工具（连接照懒，工具体首
  调用建连；`ensureConnection` 单飞防双建连）。无缓存 = 现 prepareRun
  懒发现路径不变。
- **改动 13（发现对账）**：`syncServer` 重写为对账形态——建连 tools/list
  → 与在册面 diff（删 / schema 或描述变重注册 / 新增）→ 写缓存 → 差异
  非空 emit `tools/source-changed`。ServerEntry 结构升级：`tools:
  Map<finalName, FaceEntry>`（定向回收）+ `connecting` 单飞位。新增
  `redetect()` 公开入口（清 synced 后重发现——listChanged/管理面/测试
  共用对账通道）。
