## 动机

memory-delta 重复注入事故（白箱推导 + sandbox/mem-bug-repro 复现）：注入水位寄居账本注入行，靠 records() 读面扫描回收——三轮补丁（cr-46 串台防御 / cr-1102 读面迁移 / cr-1107 payload 显式化）仍随账本层演化反复炸。触发链：v1 无 seq 行永踞 recordsFor 投影尾部（排序缺陷）→ 锚扫描永命中 10 月旧行 → S 冻结 → 每 run 全量重注。

## 改动面

- packages/ac-memory/src/index.ts：
 - 删锚扫描整段（session.records 消费、agent_id 匹配、payload/正则双通道）。
 - 新增私有水位：files/<agentId>/memory/.anchors.json（{会话键: 已注入条目水位}，per-Agent×会话）；anchorOf 读（fail-soft，坏文件=无锚）、setAnchor 写（tmp+rename 原子、S 单调不降；H<S 快照重定后回落到 H）。persist=false 走内存 Map。
 - inject 闭包：去 payload.memoryBaseline（账本行降级纯回放材料），注入后推进锚。
 - 判定纯函数化：S>H 快照重定 / S=0 且 H=0 不注 / H>S delta（origin 不等本会话）/ H=S 稳态。
- packages/ac-memory/tests/memory.test.ts：FakeSession 去 records 面；删 cr-1102 inject 形态锚检测用例（机制退役，脏账本用例覆盖其意图）；cr-46 用例语义更新；新增：脏账本零影响、锚持久化跨 Context、锚损坏自愈、H<S 回落。

## 语义裁决

- 水位粒度 per-(Agent×会话)：每桶各看各的跨会话记忆是产品语义；病灶是同桶重复注，不是多桶各注。
- 多会话并发写锚 last-write-wins 且各写各键——丢的只是对方未推进锚（下次注入重算），无损收敛。
- 崩溃窗口最坏 = 注入成功锚未落 → 重注一次同 delta（幂等）。
