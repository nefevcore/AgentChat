# cr-1094 conv-settings 批③：harnessTier 整键退役

## 判死依据（cr-1087 验尸 + cr-1092/1093 后复核）

- 键由 `ac-harness-tools` 在壳内 `ctx.convSettings.registerKey` 注册——宿主侧 `conv-settings/keys` 只回宿主注册表，UI 从不出现（双树裂痕，cr-1066）。
- grants 通路已于 cr-1092 删除（`enabled → ['harness']` 注入消失），`'harness'` 标签零消费方。
- 剩下唯一活闸 = `execute` 里的 `disabled` 拦截臂，而宿主 set 面到不了壳内注册键（写=没写）——死键双向空转。

## 改动面

- `packages/ac-harness-tools/src/index.ts`：删 `HARNESS_TIER_KEY` 定义 + `ctx.convSettings.registerKey` 调用 + `execute` 的 disabled 拦截臂 + `ConvSettingsKeyDef` type import + 行头注释的会话开关段。
- `inject` 由 `['tools', 'convSettings']` → `['tools']`——行不再依赖会话设置域（可摘除性提升：摘掉 conv-settings 行本行照常激活）。
- `run_harness` 工具本体保留（含 needPermission / 沙箱两档 / agent 互斥 / 续接凭据链，全部未动）。会话级禁用改由 **Agent 行卸载**表达。
