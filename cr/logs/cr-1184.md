# cr-1184 unread 双缺陷修复（restart_host 徽章复活 + 会话列表行徽章缺席）

## 现象
1. 每次 restart_host 后，已被点击消去的 unread 徽章在前端复活。
2. 活动栏「会话列表」按钮有数字徽章，但无法定位是哪个会话（SessionList 行无徽章）。

## 根因
### 缺陷一（复活）：cr-1057「正在看 = 已读」语义只在前端 live bump 生效，host 计数器无该语义
- host 三源（run/settled tap 桥 / UserStub 独立私信 / groups-row group/send）无条件 bump——host 不知道用户正看哪个会话；
- 前端 live bump 有活跃轴门控（activeAxis 命中即丢），但 host 侧照累积；观看期累积 = host 有、本地无；
- take 水合把 host 计数整包回放（counts.value = base 全量重置）→ 已消徽章复活。

### 缺陷二（找不到会话）：cr-1157 徽章重建只做了按钮聚合
- single 会话无名册行，行级徽章从未实现；ActivityBar 按钮是唯一提示位，用户无从定位具体会话。

## 修法（最小面）
1. `unreadStore.syncTake`：活跃轴不入 take 基线（观看期累积两侧归一——host 已被 take 清零）；
2. `unreadStore.markRead`：RPC 无条件发送（本地 0 不代表 host 0——观看期 host 侧有累积）；
3. `ConversationService` watch：离开会话时对旧轴补定向清（host 侧观看期累积由此落清）；
4. `singles/delete` · `group/delete`：连带 `clearUnread`（会话实体已删，滞留计数 = 僵尸徽章——实测 workspace/home/meta/unread.json 已滞留 3 条 single 轴）；
5. `SessionList.vue`：树行 + 搜索态行补行级徽章（AgentList .unread-badge 同配方）。

## 方案回退记录
曾实现 take 回传 taken 清单 + 前端对活跃轴补 markRead 的方案，推演发现多余（take 已清 host，回环 markRead 只是把刚清过的键再清一遍）后整体回退，改走上述更小面。
