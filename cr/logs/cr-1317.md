# cr-1317 对等 Agent 完成回执注入防自激引导行

日期：2026-11-25　状态：doing → done　引用：→cr-712（completion 回执链路）

## 动机

2026-11-25 提出人风栗（报告：`workspace/home/files/admin/report-agent-echo-20261125.md`）：
两个 Agent 经 `send_agent` 互发消息时形成无终止回声往返——`notifyCompletion`
把对端终稿回执转投发起会话并唤醒发起方，发起方醒来自然再发一条，闭环
（admin⇄mathematician 全天拉几十轮，实证）。与设计偏离：对端处理完不应把
终稿回传发起方会话之外的往返链。

## 根因（报告已核，本次复核一致）

- **根因 A（本次修）**：cr-712 把「子 Agent 回执」泛化到「对等 Agent 委托」时，
  `notifyCompletion` 对 `!fromChild` 也转投发起会话并唤醒发起方。`replyTo:'user'`
  防住了 A 终稿回投 B，没防 notice 唤醒 A——两个方向都通才构成闭环。
- **根因 B（不修，记录在案）**：`notifyCompletion` 硬编码 `budget: 1` 每轮重置满额，
  budget TTL 对回声链不提供保护。报告 4.1 节裁决：硬截断会落在正事中间、阈值
  难定、掩盖真缺的「何时停」判据——故改引导不改 budget。
