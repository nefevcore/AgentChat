# cr-1137 · unread 徽章错位根因修：routeDialog 兜底分支词法闸

日期：2026-11-16 · 状态：done

## 现象

未读数字徽章时常赋予到其他会话（Agent X 徽章 +1，点进去无对应消息）。

## 根因

routeDialog 兜底分支宽进：presence（knownSingles/knownGroups）是异步 RPC 拉取后才填充的前端副本，刷新/首载窗口期内 single 会话帧（uuid 形 conv）、群 run 过程帧（g- 前缀）、子 Agent 会话帧（sub_ 前缀）不含 `~` 时全部落 `directDialog(agent)` —— unread +1 记到 `pair:agent|user`，消息体随后被历史首屏替换冲掉 → 幽灵徽章。cr-1120 修了集合污染（knownSingles 拒脏入），本批修未就绪窗口的兜底分支。

## 改动面

- 新增 `packages/ac-client-ui-conversation/client/dialogIdLex.ts`：SINGLE_SESSION_ID_RE 并源（原 index.ts 内联常量迁出，routeDialog 与 trackKnownSingle 同一谓词）。
- `chatOps.ts routeDialog` 兜底分支词法闸：conv 为 uuid 形 / `g-` 前缀 / `sub_` 前缀 → 返回 null（丢弃）。裸 agentId（loop 直连）与对桶键行为不变。
- 回归测试 `tests/route-dialog-lex-gate.test.ts`（8 例）。
