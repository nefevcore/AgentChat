# cr-1133 viewer 镜像域读面归一：agent 发言误投为 user 轮

- **日期**：2026-11-16
- **标签**：#session #webui
- **状态**：done
- **承接**：cr-1132（用户报告长会话 agent 消息渲染成 user 消息）

## 现象

neko~user「谢谢喵～」/ admin~user「明白了——」等 agent 发言渲染为右侧 user 气泡。

## 根因（数据面 × 读面双层）

1. **数据面**：对桶会话的历史住 `agents/user`（viewer 端点域）——镜像双写时代的
   双边行镜像 + journal 全量镜像；10-22 迁移工具还造了 `migrated-msg-*` 伪 run
   （把每条历史消息转成 journal-step + settled）。
2. **读面**：foldSession 只剔目录名 `viewer` 的域（旧布局），`agents/user` 被当普通
   agent 域并入；盲区投影的 `agent_id = rf.domain`（= 'user'）——镜像 journal 的 run
   无 agent 域终稿锚时按 domain 投出 assistant/user 行。
3. **前端**：`agent_id === VIEWER_ID('user')` → UserMessage 气泡（右侧）。

admin~user 机制：空终稿行（content=''）不进终稿层 → viewerRuns 漏锚 → 镜像 journal
的 run 盲区重投（agent_id='user'）。neko~user 机制：migrated 伪 run 无账本锚 → 同径。

## 修复（fold.ts 读侧归一，落盘不动）

- 盲区行归属正源 = 同 run 账本 speech 行的 agentId（`speechAgentOfRun`），
  缺席回落 rf.domain——镜像域 run 的 domain 是镜像端点不是发言者；
- migrated 伪 run（viewer 端点域 + 无账本锚）不投——正文已由真实消息行承载；
- viewer 端点判定 = 对桶键 `<agent>~user` 中的 'user' 段（singles 无 '~' 不受影响）。

## 验证

- 真实数据根：admin~user / neko~user user 轮泄漏 agent 文本 = 0；「明白了——」挂
  admin 轮、「谢谢喵」挂 neko 轮；投影正文 0 丢失（56 条非空正文全在轮内）；
- ac-ledger 84 / host-webui+ledger 170 测试全绿；lint / typecheck 全绿。

## 非目标

- `agents/user` 镜像域的物理清理（迁移工具善后）不在本 CR——读面已免疫。
