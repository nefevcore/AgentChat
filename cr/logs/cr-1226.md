# cr-1226 groups 行 boot 装载日志（ISSUE-19 可观测性）

## 判定先行
ISSUE-19 原判「群注册表重启后静默空窗」经读码排除数据通路缺陷：`list_groups` 壳侧 GroupShim 直读磁盘（`listGroupConfigs`），不经宿主内存注册表——成员表判定不可能因重启空窗。11-15 空窗最可能是时序性（boot 窗口数据根尚未就位），单发未复现（11-16 起连续 0 例）。**残余缺口是可观测性**：宿主日志对群装载零记录（实测最新 host log 全文无 group 行），空窗只能从 Agent 侧 count=0 倒推。

## 修法（可观测性）
groups-row boot 段装载量显性化：非空 info「[groups] 群注册表装载 N 条：gid…」；空装载 warn 级——`meta/groups` 下有目录但读不出有效 group.json（疑似损坏/迁移中断）时点名目录数请核查，目录不存在（真无群）标「正常」。

## 验证
typecheck + ac-host-rows 包测试全绿。空窗若复发，下一轮 boot 日志即有定位线索。
