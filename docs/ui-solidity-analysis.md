# 页面样式"虚、不扎实"根因分析

> 日期：2026-08-09
> 方法：抓取当前运行页面（亮/暗两主题）关键元素的**实际计算样式**，量化定位问题。
> 结论：不是审美问题，是**六个可量化的样式缺陷**叠加——核心是"AI 消息无容器 + 全界面无投影 + 背景层级扁平"。

---

## 1. 核心结论

界面"虚"的感觉来自三个叠加因素：

1. **AI 消息完全没有视觉容器**（最大来源）—— `.assistant-bubble` 无背景、无边框、无投影，回复是"裸文字"贴在背景上；而用户消息有气泡。视觉严重失衡。
2. **全界面没有"重量感"**—— 列表项、卡片、输入框、思维链全部 `box-shadow: none`，元素不"浮起"，像贴纸贴在玻璃上。
3. **背景层级扁平**—— 各区域背景色相差不足 10 个亮度值，面板之间没有明暗层次。

---

## 2. 实测数据（计算样式）

### 亮色主题（html.light）

| 元素 | 实测值 | 问题 |
|---|---|---|
| body 背景 | `#f7f7fb` | 近白 |
| 会话列表背景 | `#f8f9fa` | **与 body 几乎同色**（差 3 个亮度值）→ 无层级 |
| 会话区背景 | `#ffffff` | 纯白，与列表差异极小 |
| 列表选中项 | 1px 蓝边框，`box-shadow: none` | 无投影、无光晕 |
| 输入框 | 边框 `#e0e0e0`，`box-shadow: none` | 边框极淡、无投影 |
| **AI 消息** | **背景透明、无边框、无投影** | **裸文本！** |
| 用户消息 | `#eef2ff` 气泡，圆角 6px | 有容器（对比失衡） |
| 思维链头 | 无背景、无边框、无投影 | 无容器 |
| 列表摘要文字 | `#95a5a6` | 对比度不足（浅灰） |
| 时间分隔 | `#95a5a6` | 对比度不足 |

### 暗色主题（html.dark）

| 元素 | 实测值 | 问题 |
|---|---|---|
| 会话列表背景 | `#2d2d2d` | **比内容区 `#1a1a1a` 更亮** → 层级"反了" |
| 会话区背景 | `#1a1a1a` | — |
| 列表项 | 背景/边框透明，`box-shadow: none` | **暗色下选中态几乎消失** |
| 输入框 | 边框 `#333`，无投影 | 边框在暗底上几乎不可见 |
| AI 消息 | 裸文本（无容器） | 同亮色 |
| 列表摘要 | `#7f8c8d` | 暗灰，对比度弱 |

---

## 3. 六大根因

### ① AI 消息无容器（破坏性最大）
```
.assistant-bubble { 背景: transparent; 边框: 0; 阴影: none; }
```
AI 回复完全"裸奔"。用户气泡是 `#eef2ff` 泡泡，AI 却是漂浮文字。这一条单独就足以让界面"虚"——**一半的视觉主体没有物感**。

### ② 全界面无投影（无"物体感"）
列表项、输入框、思维链、工具卡全部 `box-shadow: none`。投影是"物体浮在表面上"的主要线索；没有投影，一切像贴在玻璃上。

### ③ 背景层级扁平（无"空间感"）
- 亮色：body `#f7f7fb` / 列表 `#f8f9fa` / 内容 `#fff` —— 三层几乎同色
- 暗色：列表 `#2d2d2d` 反而**比内容区 `#1a1a1a` 亮**（层级颠倒）
界面没有"哪层浮在哪层之上"的立体感。

### ④ 边框过浅（分隔无力）
亮色边框 `#e0e0e0`、暗色 `#333`——分隔线弱到几乎不存在，区块之间靠"贴在一起"而非"分隔开"。

### ⑤ 辅助文字对比度不足（整体发灰）
`#95a5a6`（亮）/ `#7f8c8d`（暗）大面积用于摘要/时间/次要信息，对比度约 2.5:1（远低于 4.5:1 标准），界面呈现"灰蒙蒙"。

### ⑥ 旧令牌体系本质平庸
当前 `--color-*` 是传统扁平方案的浅灰板：**没有"表面层级"概念**（surface/raised 的明暗梯度）、**没有发光/投影令牌**、对比度未设计。这套体系无论怎么调局部，整体"虚"的底子都在。

---

## 4. 新设计系统（星群×工坊）如何根治

| 根因 | 新系统解法（tokens 已就绪） |
|---|---|
| ① AI 消息无容器 | 重写时给 AI 回复设计**明确的气泡/卡片容器**（星色描边 + 背景） |
| ② 无投影 | `--shadow-panel` / `--shadow-pop`（面板投影）、`--glow-soft`（星卡柔光） |
| ③ 层级扁平 | 四级背景 `--bg-deep/base/surface/raised`，层次分明（深空实测已见：`#0a0d14/#0e121b/#141927/#1b2134`） |
| ④ 边框过浅 | `--line` / `--line-strong` 双档位，且深空下用 `rgba(255,255,255,.08/.16)`（比 `#333` 更可感知） |
| ⑤ 对比度不足 | 文本三档 `--text-1/2/3`，主文本 ≥14:1，弱文本也在可读范围 |
| ⑥ 令牌平庸 | 新 tokens 全部包含上述能力，组件引用令牌即可 |

**一句话**：现在"虚"是因为**旧的扁平浅灰体系缺了"层级、投影、容器、对比度"四个维度**；新设计系统的令牌已经把这四个维度补齐（`--bg-*` 层级、`--shadow-*`/`--glow-*`、`--line*`、`--text-1/2/3`），重写时接入即根治。

---

## 5. 可在重写前做的低风险即时改进（可选）

如果想让**当前页面**先"扎实"一点（不改架构），可快速：
1. 给 `.assistant-bubble` 补一个浅色背景 + 细边框（如 `rgba(0,0,0,.03)` 底 + `var(--line)` 边）——立刻消除"裸文本"
2. 给列表项/输入框/工具卡补 `box-shadow: 0 1px 3px rgba(0,0,0,.06)` 微投影
3. 辅助文字 `#95a5a6` → `#7f8c8d`（提高一档对比度）
4. 暗色下把列表背景调暗一级（`#2d2d2d` → `#252525`），修复层级颠倒

> 但这些都是治标；真正的根治在重写时切换到新 tokens + 气泡/投影设计。
