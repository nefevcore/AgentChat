# AgentChat WebUI 用户操作手册

> 面向使用者的功能说明：界面里有什么、每一步怎么操作。
> 对应源码轨道 `src/ui/webui`，文档只描述实际存在的功能；个别"看得见但点了没反应"的入口已如实标注。

---

## 1. 界面总览

打开 WebUI（默认 `http://localhost:3830`）后，整个界面分为四个区域：

```
┌──┬────────────┬──────────────────────────────┬───────────┐
│ ① │ ② 列表区    │ ③ 主区（聊天 / 运行矩阵）      │ ④ 工作区    │
│ 图 │ Agent 列表 │  · 与 Agent 对话              │ 文件树      │
│ 标 │ 会话列表   │  · 群聊 / 独立会话             │（按需展开）  │
│ 栏 │ 运行跟踪   │  · 运行跟踪大矩阵              │           │
└──┴────────────┴──────────────────────────────┴───────────┘
```

| 区域 | 说明 |
|---|---|
| ① 图标栏（最左 48px） | 头像、三个列表页签切换、Token 用量、主题切换、插件按钮、设置、更多菜单 |
| ② 列表区 | 三个页签三选一：**Agent 列表**（Agent+群组混排）、**会话列表**（独立会话）、**运行跟踪**；宽度可拖动调整 |
| ③ 主区 | 默认是聊天窗口；从运行跟踪可切换为"运行矩阵"大画布，切回不打断正在生成的回复 |
| ④ 工作区（右侧） | 默认收起；点击聊天区右缘的悬浮把手展开，浏览数据目录文件 |

**窄屏 / 手机（≤768px）**：列表区变成从左侧滑出的抽屉（点击遮罩关闭）；工作区变为覆盖式面板。

## 2. 开始一段对话（1v1）

1. 在左侧 **Agent 列表** 点击一个 Agent。
2. 在底部输入框输入消息，**Enter 发送**，**Shift+Enter 换行**。
3. 回复开始后可以看到：
   - **思考过程折叠栏**（如果模型支持思考）：标题如"思考过程（共 2 步，共用时 12 秒）"。生成中自动展开、滚动时标题吸顶；生成结束自动折叠。点击可随时手动展开/收起。
   - **工具卡片**：Agent 调用工具（执行命令、读写文件、搜索等）时出现。执行中显示动画和"正在执行…"；完成后展示该工具的专属卡片（见第 5 节）。
   - **最终回复**：Markdown 渲染，支持代码高亮、数学公式、表格。

### 回复过程中可以做的

| 操作 | 方法 |
|---|---|
| 打断生成 | 输入框右侧发送按钮会变成橙色"打断并发送"，点击即中断当前生成并发送新消息 |
| 上翻看历史 | 直接向上滚动即可——一旦上滚，自动跟随暂停，右下角出现"回到底部"悬浮按钮；滚回底部附近自动恢复跟随 |
| 加载更早的消息 | 滚动到顶部自动加载上一页，视口位置保持不跳 |

### 断线提示

顶部出现"[WARN] 连接已断开，正在重连..."横幅时，页面会自动重连（无需刷新）；断线期间发出的消息会在重连后自动补发。

## 3. 消息上的操作

把鼠标悬停到消息上，会出现操作按钮：

| 消息类型 | 可用操作 |
|---|---|
| 我发的消息 | **复制**、**编辑**（改完按 Enter 重新发送，Esc 取消；编辑会截断这条之后的所有消息并重新生成）、点击附件名预览文件 |
| Agent 的回复 | **复制**、**重新推理**（删掉这条回复重新生成）、**删除**（删除这条回复） |
| 代码块 | 代码块右上角有 **复制按钮**，点击后变绿"已复制" |
| 文件路径 | 回复正文里的文件路径（如 `./src/index.ts`）和 `<file>` 标签会显示为可点击链接，点击直接打开**文件预览** |

> 注意两点实况：带思考过程的回复才有生效的"重新推理/删除"按钮；纯文本回复上的同名按钮目前点击无效。"继续生成"功能存在但按钮尚未启用。

## 4. 输入框的全部能力

| 能力 | 操作 |
|---|---|
| 多行输入 | 默认 3 行高度，Shift+Enter 换行 |
| 发送附件 | 点回形针按钮选择文件（可多选），以文件名 chip 列出，可单个移除；随消息一起发送 |
| 思考强度 | 输入框内的选择器：关 / low / **high（默认）** / max，控制 Agent 回复时投入多少思考 |
| 决策交互 | Agent 反问时，输入框上方出现**决策药丸**（见第 6 节） |
| 群聊模式 | Agent 回复期间输入框锁定，显示"Agent 回复中..."，投递完成后解锁 |
| 归档期间 | Agent 正在归档整理记忆时，输入框提示"稍后处理您的回复…" |

## 5. 工具卡片（Agent 干活时你会看到什么）

每种工具有专属卡片，均可点击标题栏展开/折叠（执行中自动展开）：

| 卡片 | 你会看到 |
|---|---|
| 终端（bash） | 执行的命令、工作目录、标准输出、红色标准错误、退出码徽标、超时/截断警告 |
| 读文件（read） | 文件名 + 语言徽标 + 大小/行数 + 语法高亮的代码（带行号风格）；读目录时显示文件清单和计数 |
| 写文件（write） | 文件名链接；**点击弹窗**查看写入的完整内容（高亮显示） |
| 改文件（edit） | 文件名、替换了几处、首次变更行号，以及**红绿行级对比（diff）**，可复制 diff |
| 网页搜索（web_search） | 搜索词、耗时、结果数、AI 摘要、每条结果的标题（可点击，仅 https）、摘要与相关度分数；长摘要可展开 |
| 浏览器（browser / fetch_webpage 等） | 批量操作时显示步骤统计与每步动作徽标（打开/点击/输入/截图…）；截图需点"预览截图"按需加载，悬停放大；网页正文过长可展开 |
| 子 Agent（subagent） | 四种卡片：创建（ID+状态）、等待结果（结果+耗时）、活跃清单、终止 |
| 其他工具 | 通用折叠卡，显示原始输出文本 |

状态徽标含义：**运行中**（黄色三点动画）/ **OK**（绿）/ **ERR**（红）/ **BLK**（黄，被安全策略阻止）。

## 6. 回答 Agent 的提问（决策交互）

当 Agent 需要你拍板时（ask_questions 工具），输入框上方出现一个**药丸按钮**（显示问题摘要），并自动展开一次：

1. 点击药丸展开菜单：显示提问的 Agent、完整问题、若干**选项按钮**。
2. 点选一个选项即提交；也可在底部输入框输入自定义答案后按 Enter 或点"回复"。
3. 超时未作答时，药丸会自动消失。

> 该提问只在它所属的会话里显示，不会串到别的会话。

## 7. 文件预览

从消息里的文件链接、附件 chip、工作区文件树都能打开**文件预览弹窗**：

| 类型 | 效果 |
|---|---|
| 图片（png/jpg/gif/webp/svg/ico） | 直接显示 |
| Markdown | 渲染后显示 |
| 代码/文本 | 语法高亮 + 行号列（约 40 种语言），底部有复制按钮 |
| HTML | 沙箱内预览，可"新窗口打开" |
| 其他二进制 | 仅显示文件信息 |

- 弹窗顶部显示文件名、类型、大小，底部显示完整路径。
- 按 **Esc** 或点遮罩关闭。
- Agent 写的相对路径打不开时，会自动按该 Agent 的文件目录再试一次。

## 8. 群聊

**创建群组**：Agent 列表右上"+"→「创建群组」→ 填名称（必填）、描述 → 勾选参与者（排除你自己）→ 创建。

**群聊界面**：
- 消息按成员分左气泡，只读（不能编辑/删除群消息）。
- 发消息后等 Agent 们回复（回复期间输入框锁定，最长 10 秒自动解锁兜底）。
- 右上**群信息按钮**打开抽屉：查看/搜索成员（按 ID 搜索）、修改群名称与简介（点"保存"，按钮变绿即成功）、删除群组（红色按钮 + 确认）。

> 目前不支持：退出群聊、添加/移除成员。群组条目没有"运行中"光环（谁能发言由 Agent 自主决定，无法预判）。

## 9. 独立会话（单议题工作台）

左侧第二个页签「**会话列表**」管理独立会话——每个会话有自己的标题、Agent、模型与工作目录，适合单议题任务归档保留。

### 会话树结构

```
工作区 A（你登记的本机文件夹）
 ├─ 会话 1（正在运行 → 头像带光环）
 └─ 会话 2
未分组
 └─ 会话 3
```

### 基本操作

| 操作 | 方法 |
|---|---|
| 新建会话 | 顶部「新增」按钮（自动复用已有的空会话）；或某工作区行内"+"在该工作区下建 |
| 进入会话 | 点击会话条目 |
| 删除会话 | 悬停会话行 → 删除按钮 → 确认（**连同消息彻底删除，不可恢复**） |
| 归档会话 | 在该会话的聊天页 更多菜单 →「归档独立会话」（软删除，消息保留） |
| 登记工作区 | 「新增工作区」→ 点「选择」弹出**系统原生文件夹选择框**，或直接粘贴文件夹绝对路径 → 可选命名 |
| 工作区重命名/删除 | 悬停工作区行 →「更多」菜单（删除工作区不会动你的文件夹，其下会话移入"未分组"） |

**挂了工作区的会话**：Agent 运行时可以把该文件夹纳入可访问范围（沙箱白名单）。

### 会话内专属设置（输入框上方三个下拉）

| 下拉 | 作用 |
|---|---|
| 工作区 | 把会话挂到某个工作区/未分组 |
| Agent | 选择执行者（默认预设 + 其他预设 + 常规 Agent）；**已有消息的会话不能再换 Agent**（显示锁图标） |
| 模型 | 从模型池选一个覆盖该会话的模型；选"默认模型"则回落 Agent 配置 |

## 10. 运行跟踪（谁在跑、聊了多少）

左侧第三个页签「**运行跟踪**」：

### 面板（侧栏）

- **运行总览**：点击打开主区的**运行矩阵**大画布（再点关闭）。
- **运行中**：当前所有正在运行的会话清单，每项显示实时已运行时长；悬停出现红色**中断按钮**可远程打断；点击条目直接跳进该会话（Agent↔Agent 的运行没有可打开的视图，仅展示）。
- **活跃子 Agent**：当前派生出去的子 Agent（名字 · 所属父 Agent · 任务 · 时长）。

### 运行矩阵（主区）

一张"成员 × 成员"的热力图：格子颜色越深表示选定时间范围内消息越多；**正在运行的格子**带旋转光环；对角线是自会话/群本体。

- 顶部切换时间范围：1 小时 / 1 天 / 3 天 / 1 周（默认）/ 1 月 / 全部。
- 悬停任意格子：十字高亮该行该列，浮窗显示两端名称、关系、消息量、字节数、最近活跃、运行详情。
- **点击格子的效果**：群 → 进群聊；你参与的对话 → 进该 1v1 聊天；其他（Agent↔Agent、自会话、系统触发）→ 打开**只读"会话对"视角**（双方消息都靠左、可上翻加载历史、无输入框），左上角"返回"回到矩阵。
- 底部"覆盖面分析"可折叠：说明哪些会话已入矩阵、多少独立会话在矩阵外。
- 数据每 3 秒自动刷新（页面切到后台时暂停），无需手动刷新。

## 11. Token 用量统计

图标栏图表按钮打开「Token 用量统计」弹窗：

- **左侧**：时间范围（近 7 / 30 / 90 天、全部、自定义起止日期）；摘要区显示缓存命中率（进度条）、总输入、总输出、总步数、请求数。
- **总览页签**：**Agent 协作弦图**——外环是各 Agent，弦是两两之间的对话流量。悬停一条弦只亮它和两端；悬停一段弧亮起该 Agent 的全部协作。默认不含你（user）和自言自语流量，勾选"包含 user / self 流量"可加入。
- **用量统计页签**：按日堆叠柱状图，可切换"缓存"（缓存/未缓存/输出三段）或"模型"（各模型用量，取前 7 个，其余合并为"其他"）；悬停柱子看明细。
- 打开期间每 30 秒自动刷新，也可点「刷新」。

## 12. 管理你的 Agent

### 快速新建（Agent 列表）

列表右上"+"→「新增 Agent」→ 填名称（ID 可留空自动生成）→ 从下拉选模型池（或用全局配置）→ 创建后立即出现在列表中。

### 完整管理（设置面板）

点图标栏齿轮打开「设置」，左侧选「Agent 设置」：

- **列表页**：搜索（名称/ID/标签）、新建、删除（红色确认，会连同会话历史与凭据一起删除）；卡片上的标签 chips 表示能力（base 基础 / admin 系统管理 / dev 开发工具 / conductor 子代理编排）。
- **编辑页**（点击任一 Agent 进入，共 5 个页签）：

| 页签 | 能配置什么 |
|---|---|
| 基本信息 | **头像**（≤2MB，悬停可移除）、昵称、**能力标签**（点击切换 admin/dev/conductor，可添加自定义领域标签）、**SYSTEM.md / AGENT.md**（开关 + 全文编辑，定义系统提示词与角色） |
| 模型 | 从模型池选一个，或"默认(继承全局)"；每个字段可单独覆盖——被覆盖的字段有"本 Agent"徽标和**恢复继承**按钮；顶部"当前生效"显示最终模型及其来源；点"读取"可从服务商拉取可选模型列表 |
| 定时任务 | 见第 14 节 |
| 安全 | 路径白名单（每行一个路径；留空则仅允许工作区内），控制 Agent 可访问的目录 |
| 扩展与工具 | 该 Agent 启用哪些插件/钩子/工具（见第 13 节） |

右上角有**上一个/下一个**按钮按列表顺序切换 Agent。

> 改完配置记得点右下角**保存配置**；提示"下次运行生效"。未保存就关闭面板会弹出"放弃未保存的更改?"确认。

## 13. 插件、钩子与工具（扩展与工具）

设置面板的两个入口：「扩展与工具」看全局目录（只读）；Agent 编辑页的「扩展与工具」页签做实际装配。

- **插件组**：开关决定该 Agent 是否加载此插件；卡片显示来源（内置/已安装/开发中/会话）、版本、权限徽章；"声明但未授予"会有黄色警告。
- **钩子区**：七个执行阶段（请求前/步骤开始/工具执行前后/步骤结束/响应后/兜底）；拖动把手可调整顺序，或点"按推荐顺序排序"一键重排；标 `automatic` 的基础设施钩子不可停用。
- **工具区**：每个工具三态——默认 / 显式开启 / 已停用；**如果缺少所需能力标签，开关是禁用的**（灰色 chips 提示缺什么），去"基本信息"补标签即可。

### 插件库（设置 → 插件库，四个页签）

| 页签 | 用途 |
|---|---|
| 已安装 | 查看已装插件（提供多少工具/钩子）；**卸载**（确认后源码移入备份目录，可恢复） |
| 待审暂存 | 人工审查流：点「审查文件与授予」打开审查弹窗——逐文件查看源码内容、**逐一勾选要授予的权限**（涉及 UI/进程的权限有醒目警告），未勾完不能批准；也可直接「拒绝」 |
| 开发目录 | 本地 `<workspace>/plugins/<agentId>/<name>/` 下的插件：**注册会话**（立即加载，热重载，重启失效）、卸载、**发布**（转待审走人审） |
| 市场 | 从 GitHub topic 搜索社区插件；支持**离线浏览本地缓存**；点安装——若插件需要高危权限会自动转入待审让你人工确认 |

## 14. 定时任务（让 Agent 定时干活）

### Agent 级（Agent 编辑 → 定时任务）

| 模式 | 含义 |
|---|---|
| time | 指定日期+时间触发一次/每天 |
| delay | 间隔触发（如每 1h，支持 30s / 5m / 2h30m 写法） |
| random | 在 min~max 范围内随机延时 |
| workday | 每个法定工作日的指定时间 |
| holiday | 每个法定节假日的指定时间 |

每条任务：启用/暂停开关（停用显示删除线）、提示内容（触发时发给 Agent 的指令，支持 `{{now}}` `{{time}}` `{{date}}` 占位符）、目标（逗号分隔多个 Agent，默认 user）、重复次数（0=永久）。

### 全局定时任务（设置 → 定时任务）

对全部/指定 Agent 生成的系统级任务；内置的**全局归档**与**数据备份**系统任务带 🔒 不可删除。归档任务会在深夜批量整理活跃 1v1 会话的记忆。

## 15. 模型与搜索凭据池（设置 → 模型管理 / 搜索引擎）

管理多个服务商配置，切换不用改代码：

- **条目操作**：设为默认（★ 标记，同时全局引用指向它）/ 编辑 / 删除。
- **编辑弹窗**：Provider 下拉列出所有受支持服务商（openai / deepseek / glm / ollama / tavily / serpapi / brave…），选中后表单按该服务商需要的能力动态生成；API Key 输入框有按住眼睛查看。
- 第一条添加的条目自动成为默认；改完在设置面板底部**保存配置**落盘。

## 16. 全局配置与其他系统功能

| 功能 | 位置与操作 |
|---|---|
| 全局配置 | 设置 → 各命名空间配置（日志、定时、工具默认参数等），schema 驱动表单 |

| 重启后端 | 设置面板底部「重启后端」（确认后执行；进行中任务会被中断；期间界面提示自动重连） |

## 18. 常见情景速查

| 想做什么 | 去哪里 |
|---|---|
| 找 Agent 聊天 | 左 1 页签 → 点 Agent → 输入框发消息 |
| 让两个 Agent 讨论给我看 | 建群组拉他们进群；或从运行矩阵点它们的交叉格只读围观 |
| 开一个单议题任务不打扰主对话 | 左 2 页签 → 新增 → 会话内选 Agent/模型/工作区 |
| 看现在谁在跑、跑多久了 | 左 3 页签（运行中清单）或打开运行矩阵 |
| 我这个月 token 花在哪了 | 图标栏 Token 用量 → 切范围/看弦图与柱状图 |
| 给 Agent 换个模型 | 设置 → Agent 设置 → 模型页签（选池或覆盖字段）；单个会话临时换用输入框上方的"模型"下拉 |
| 让 Agent 每天早上汇报 | Agent 编辑 → 定时任务 → time 模式 |
| 加一个新模型服务商 | 设置 → 模型管理 → 编辑条目 → 保存配置 |

## 19. 已知限制（使用者需知）

- 对话内无消息搜索、无导出；输入框不支持 @提及、引用回复、历史命令上下翻；草稿切换会话不保留。
- 群聊只能建/改名/删除，不能退出、不能增删成员。
- 独立会话一旦有消息就不能更换 Agent（模型仍可换）。
- Agent↔Agent 的运行只能只读围观，不能插话。
- Token 统计不覆盖群聊维度，也不能导出文件。
- 工具被安全策略拦截时只显示 ⛔ BLK 徽标，没有"批准执行"按钮。
