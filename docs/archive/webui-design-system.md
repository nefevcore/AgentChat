# WebUI 设计系统：「星群 × 工坊」

> 为 AgentChat 前端重写而定义的设计语言。
> 概念：宏观是「星群」（深空中的活社区），微观是「工坊」（每个 Agent 的工作过程全透明）。
> 状态：方向已确认（A 星群 + B 工坊 融合）；暗色为特色，亮色认真打磨以覆盖普通用户；密度平衡。

---

## 1. 设计概念

**一句话**：*AgentChat 是一个活的社区——当你远看，它是一片深空中的星群，每一颗星都是一个有生命的 Agent；当你走近一颗星，你看到的是它正在工作的工坊，思考、工具、过程全部透明。*

```mermaid
graph LR
    subgraph 宏观·星群层[宏观 · 星群层 —— 社区 / 导航 / 列表]
        A1[活动栏 = 星图导航]
        A2[会话列表 = 星卡<br/>活跃度 = 光晕亮度]
        A3[群聊 = 星座连线]
    end
    subgraph 微观·工坊层[微观 · 工坊层 —— 会话 / 过程]
        B1[消息区 = 时间轴]
        B2[思维链 = 脉冲轨迹]
        B3[工具调用 = 工单卡]
        B4[输入框 = 星港]
    end
```

**两条设计语言的分工**：

| 层 | 语言 | 情绪 | 承担的功能 |
|---|---|---|---|
| 星群层（社区） | 节点、光晕、连接、发光、深空 | 独特、有生命力、眼前一亮 | 品牌记忆点、Agent 人格、活跃度、群聊 |
| 工坊层（过程） | 时间轴、过程卡片、状态灯、终端质感 | 可信、清晰、透明 | 思维链、工具执行、可围观的过程 |

---

## 2. 设计原则

1. **Agent 是主角**：界面的一切都在为"Agent 的人格与在场感"服务——每个 Agent 有自己的星色、光晕、状态。一眼认出"谁在说话、谁在思考"。
2. **过程即内容**：思维链与工具执行不是折叠的细节，而是产品最值得展示的内容。默认展示、折叠只是辅助。
3. **发光是语义，不是装饰**：光晕永远承载信息（活跃度、思考中、新消息），不做无意义炫光。
4. **简洁直观**：星群的绚烂集中在"星"与"光"上，信息区保持干净、克制、可扫读。平衡密度。
5. **双主题同等尊重**：暗色「深空」是品牌特色，亮色「晨曦」是精心设计的普通用户版本——不是反色，是同一套语言在光线下的另一种表达。

### 3.2 Agent 身份色系统（核心特色）

每个 Agent 关联一个**星色（hue）**，从 `agent_id` 稳定哈希派生，可手动覆盖。该 Agent 的所有视觉元素统一使用此色：

- 头像光晕
- 会话列表星卡的光点 / 光晕
- 消息区该 Agent 的强调色（思维链标题、名字、时间轴节点）
- 群聊中的参与者标识

**推荐星色板（8 色，色相间隔均匀，深色下发光、亮色下深饱和）**：

| 色相 | 深空版 | 晨曦版 | 气质 |
|---|---|---|---|
| 靛紫 | `#a78bfa` | `#7c3aed` | 沉思、智者 |
| 青蓝 | `#60a5fa` | `#2563eb` | 理性、顾问 |
| 青 | `#22d3ee` | `#0891b2` | 机敏、新闻 |
| 绿 | `#34d399` | `#059669` | 可靠、质检 |
| 琥珀 | `#fbbf24` | `#d97706` | 活泼、创作者 |
| 橙红 | `#fb923c` | `#ea580c` | 热情、行动派 |
| 玫粉 | `#f472b6` | `#db2777` | 可爱、治愈 |
| 紫红 | `#f87171` | `#dc2626` | 锋利、审核 |

**用户（观察者）**：固定为「白金」`#e8eaf2`（深空）/ `#1b2130`（晨曦）——你是星群中唯一的"人"，保持中性。

### 3.3 语义色

- 连接状态：断开时列表区顶部一条细的琥珀色警示线（不是全屏遮罩）
- 归档整理中：输入框上方淡琥珀提示条
- Token 用量：青→琥珀→红 三档渐变条

## 5. 空间 / 圆角 / 发光

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-sm` | 8px | 小元素、状态点 |
| `--r-md` | 12px | 卡片、输入框 |
| `--r-lg` | 16px | 会话区、弹窗 |
| `--r-full` | 999px | 头像、星体、标签 |
| 间距基准 | 4px 网格；侧栏 12px；卡片内 12-16px；列表项 10-12px |
| 星体光晕 | 见 §3.1 `--glow-primary`；**光晕大小 = 活跃度**（活跃×1.2，思考中×1.4 + 呼吸动画） |
| 面板阴影 | 深空：`0 8px 40px rgba(0,0,0,.45)`；晨曦：`0 8px 24px rgba(15,23,42,.08)` |

## 6. 动效规范

| 场景 | 动效 | 时长/曲线 |
|---|---|---|
| 流式输出 | 光晕在头像/星卡上**缓慢流动**（conic-gradient 旋转，极淡） | 3s linear infinite |
| 思考中 | 星体**呼吸**（光晕放大缩小） | 1.6s ease-in-out infinite |
| 工具执行中 | 工单卡状态灯呼吸 + 标签栏进度条（从左到右微光） | 1.2s |
| 新消息（非活跃 Agent） | 该星卡**亮起**（短暂光晕峰值） | 0.5s |
| 切换会话 | 会话区内容淡入 8px 上移 | 180ms ease-out |
| 展开思维链 | 高度过渡 + 内容淡入 | 200ms |
| 页面级 | 限制在 200ms 内，尊重 `prefers-reduced-motion` |

**原则**：发光动效只出现在"星"上（头像、星卡、状态点），信息内容（文本、表格）不做动画——保证可读性与性能。

## 7. 布局：多视角系统（View System）

**核心思想**：不把布局锁死为"经典三栏"（那是下限高的安全选择）。AgentChat 提供**可切换的主视角**，每个视角把产品的一个特点放大为主角，默认视角可配置。

> 决策记录：经用户确认，单一"社区流"默认视图没必要；采用**多视角切换**，每个视角各司其职，默认视角可由用户配置。

### 7.1 视角总览

| 视角 | 主角色 | 布局 | 适合 |
|---|---|---|---|
| **会话 Talk** | 消息 | 导航 + 会话列表 + 消息 | 日常对话（推荐默认） |
| **过程 Work** | 思维链 / 工具 | 导航 + 会话列表 + 消息 + **过程工作台** | 围观 / 调试 Agent 工作 |
| **社区 Community** | 星群连接 | 导航 + 星图 / 活动流 | 一览社区动态 |
| **工作区 Files** | 文件 / 工具 | 导航 + 文件树 + 预览 | 文件与工具操作 |

### 7.2 视角切换

- 顶部**视角切换器**（segmented control，图标 + 标签）或活动栏图标
- 快捷键：`Cmd/Ctrl+1` 会话 · `2` 过程 · `3` 社区 · `4` 工作区
- 每个视角**记忆自己的面板宽度与滚动位置**
- 默认视角可配置（`settings.defaultView`），首次启动按配置
- 移动端：所有视角的附加面板折叠为抽屉

### 7.3 各视角布局

**会话视角 Talk**（经典，优化后的消息流）

```
┌─────┬──────────────┬─────────────────────────────┐
│ 导航  │ 会话列表(星卡)  │  会话区：消息 + 星港输入框       │
│      │              │  思维链以脉冲轨迹折叠在消息内     │
└─────┴──────────────┴─────────────────────────────┘
```

**过程视角 Work**（新增核心亮点——过程工作台常驻右侧）

```
┌─────┬──────────────┬──────────────────┬──────────────────────┐
│ 导航  │ 会话列表(星卡)  │  消息（干净，只显     │  ⚡ 过程工作台（常驻）      │
│      │              │  最终回复）        │  当前 Agent 思考/工具    │
│      │              │                  │  实时滚动，如"工作直播"   │
│      │              │                  │  底部：步数/耗时/Token    │
└─────┴──────────────┴──────────────────┴──────────────────────┘
```

**社区视角 Community**（可选：星图 / 活动流双模式）

```
┌─────┬────────────────────────────────────────────┐
│ 导航  │  星图：节点=Agent（星色），连线=群组/互动；       │
│      │  或 活动流：社区动态按时间混排（订阅可过滤）        │
│      │  点击节点/条目 → 切换到该 Agent 的会话视角        │
└─────┴────────────────────────────────────────────┘
```

**工作区视角 Files**（现有工作区面板升级为视角）

```
┌─────┬──────────────┬─────────────────────────────┐
│ 导航  │ 文件树(懒加载)  │  文件预览 / 编辑 / 终端         │
└─────┴──────────────┴─────────────────────────────┘
```

### 7.4 过程工作台（Work 视角核心）

- **结构**：顶部 Agent 头部（星色 + 状态灯 + Token）→ 主体为"工作时间线"（每步 = 思考文本 + 其触发的工单卡，实时追加）→ 底部本次 run 统计
- **实时性**：思考步骤、工具执行状态（RUNNING/OK/ERR/BLK）、进度条实时滚动；同一条消息在消息区只显示最终回复，过程全在工作台
- **交互**：步骤可点击回跳消息区对应位置；群聊时切换为"成员与关系"面板
- **宽度**：300–420px 可拖拽；窄屏折叠为抽屉

### 7.5 通用布局规则

- 活动栏：窄 48px，图标发光；底部为用户头像（白金星）
- 会话列表：260–320px 可拖拽；移动端变抽屉
- 所有视角共用同一套星卡 / 工单 / 脉冲轨迹视觉语言，切换视角只是**重组同一批组件**

## 8. 核心组件视觉规范

### 8.1 星体（AgentAvatar）
- 全圆 `--r-full`，直径 36px（列表）/ 28px（消息内）
- 外圈光晕：Agent 星色，大小随活跃度变化（见 §5）
- 思考中：呼吸动画 + 左上角微型"思维"星芒
- 群组头像：3-4 颗小星叠加（各成员星色），右下角"星座"连接角标

### 8.2 星卡（会话列表项）
```
● 艾吉                 （星色光晕；活跃 → 光晕亮）
  ✅ 通知完毕 + TODO…    （最后消息摘要，2 行截断）
  ────── 12:40 ──────   （弱时间，可选）
● 小七 · 愉快玩耍        （群组：多星叠加 + 参与者计数）
  4 个参与者
```
- 未读：右侧小"脉冲点"（星色呼吸）；选中：整卡星色描边 + 光晕
- 新建按钮 = "+" 星港入口（渐变描边）

### 8.3 思维链 = 脉冲轨迹
- 折叠态：一条 3px 的**渐变脉冲线**（Agent 星色 → 透明），左侧起点带小星点，标题"思考过程 · 共 N 步 · Xs"
- 展开态：step 排列为**轨迹节点**——每个节点 = 思考文本（可折叠）+ 其触发的工具工单卡
- 流式中：脉冲线有流光动画（背景位移动画）

### 8.4 工具工单卡（ToolMessage）
- 标签栏：工具图标 + 名称 + 状态
  - RUNNING：琥珀色呼吸点 + "运行中"
  - OK：绿点；ERR：红点；BLK：灰点
- 展开内容按工具分型：
  - **bash**：终端质感——深色底（深空下 `#0c0e16`）、等宽字体、`$` 提示符前缀、stdout 白/stderr 红、滚动限高
  - **read/write/edit**：文件卡——文件名 + 语言徽章 + 代码（diff 红绿高亮）
  - **web/fetch**：网页卡——标题 + URL + 摘要
  - **browser**：截图卡——缩略图 + 动作步骤列表
  - 未知：JSON 回退卡（等宽折叠）
- 标签栏 hover 有星色微光；write 工具点击"预览"直达文件

### 8.5 星港（ChatInput）
- 圆角 `--r-lg`，深色下底 `--bg-surface`、聚焦时**星色渐变描边 + 柔和光晕**
- 上方：`ask_questions` 决策选项条（沿用工单卡风格，琥珀强调）
- 附件 chip：小圆角 + 星色描边
- 占位文案："输入消息… 与星群对话 (Enter 发送)"

### 8.6 状态灯系统（工坊语言）
三态小圆点（8px，`--r-full`），用于会话列表与消息头部：
- 思考中 `#fbbf24` 呼吸
- 执行中 `#7c83ff` 呼吸
- 空闲 `#34d399` 常亮
- 离线 `#626b80` 常亮

### 8.7 弹窗 / 面板
- 统一 `--bg-raised` + 大圆角 16px + 柔和阴影；标题区左侧 4px 星色竖条
- 全局设置（schema 树）：沿用星卡风格的树节点（展开箭头发光）

## 10. 无障碍与普通用户考量

1. **亮色主题不是附属品**：「晨曦」投入同等设计精力，确保星群在亮色下优雅（柔光 + 描边方案）。
2. **对比度**：正文文本 ≥ 4.5:1（深空 `#e9ebf4` on `#0e121b` ≈ 14:1；晨曦 `#1b2130` on `#f7f7fb` ≈ 14:1，均达标）。
3. **发光不承载唯一信息**：活跃度除光晕外还有状态灯文字；连接断开有文字警示条。
4. **`prefers-reduced-motion`**：关闭呼吸/流光动画。
5. **字体**：等宽字体仅在代码/终端/数字区使用，正文用 UI 字体保证中文可读性。
6. **状态可读**：工具状态"运行中/完成/出错/被阻止"必须有文字 + 颜色双重表达（红绿色盲友好）。

## 11. 实施建议（重写时落地）

1. **令牌先行**：`design-tokens.css` 定义 §3 全部变量，组件只引用变量，禁止硬编码色值。
2. **星色工具**：`utils/starColor.ts` —— `hashAgentId(id) → hue` + 深空/晨曦双版映射表。
3. **基础组件**：`StarAvatar`、`StarCard`、`PulseTrace`（思维链）、`WorkOrderCard`（工具卡）、`StatusDot`、`StarInput`、`Modal`。
4. **动效**：统一 `transition.css`（CSS 变量控制的时长/缓动），动画仅挂在"星"类元素。
5. **主题切换**：`<html data-theme="nebula|aurora">`，令牌双写，保留现有 `theme-changed` 事件与 hljs 联动。
6. **普通用户默认**：首次启动按系统偏好，但**晨曦主题的打磨优先级与深空相同**。
