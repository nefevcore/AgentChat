三、终态规格\n\n1. **文法**：行型判定 / 未知词安全忽略 / 历史形态 upcast（v1 无 seq、boundary≤0 回落、MAX_SAFE_INTEGER 归位）全部住在解析边界单处（ac-ledger-core），产出带类型 facts——下游不可构造非法行态。\n2. **解释权**：ac-ledger-core 新纯库（零 cordis 零 fs）持有行协议 + 事件词汇 + 归一化 + SessionFold + 谓词族；ac-ledger 变薄壳（fs 读面 + writer + cordis 服务面）并全量 re-export——10 个既有依赖方零改动；session-index 删 boundaryOf 改 import。\n3. **投影**：ac-archive-core 增 replayProjection（shadow 过滤 + 伪行合成 + 摘要头选择——两消费方管线的公共核）与 replayTokensFor（组合口：facts + viewer → 估算值）；shell-rows / face-ops 保留预算与目录编排，管线改调单源。\n4. **转移**：writer seq 分配器单调保持；物理重写（compact）内置 fold 前后同构对拍（回放口径投影与语义边界等价断言，fail-loud）；compaction 边界由 writer 落账时刻记死保持。\n5. **主张**：凡落盘数字（compaction stats.shadowedRows/estimatedTokens、索引 est_tokens）皆可按其声明口径重算；doctor 逐会话对拍，报告结构化（session × invariant × severity × 行锚），基线豁免表管存量。\n\n## 四、非目标\n\n- 不改压缩 V3 语义（compaction-v3-injection.md 现行设计不动）。\n- 不重写存量文件——历史形态经 fold upcast 消化，append-only 语义不动。\n- 不换存储引擎（单会话单文件单写者，存储从来不是病灶）。\n- 不全量重写 session-index 摄取（indexLine 行级分类与 core 深度并源另案；本计划只收 boundaryOf）。\n- 不做逐行在线热校验（写路径性能面不动）。\n- 不引 property-based 测试框架（同构/主张一致是确定性断言，普通用例可锁）。\n\n## 五、裁决记录（cr-1245 落锤，取代 cr-1235 §五 待裁决表）\n\n| # | 题 | 裁决 | 判据 |\n|---|---|---|---|\n| D1 | 词汇宿主 | 升维为解释权宿主：ac-ledger 拆
